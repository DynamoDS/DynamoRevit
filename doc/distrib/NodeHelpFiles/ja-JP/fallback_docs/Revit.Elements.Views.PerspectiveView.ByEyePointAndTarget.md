## 詳細
`PerspectiveView.ByEyePointAndTarget` は、視点、目標位置、名前、および `isolateElement` のブール値を使用して、Revit の新しいパース 3D ビューを作成します。

次の例では、2 つの点を Dynamo で作成し、カメラの視点と目標位置として使用しています。これらは、名前およびブール値とともに `PerspectiveView.ByEyePointAndTarget` への入力として使用します。出力は、視点から目標位置の方向を向いた Revit の新しいパース ビューです。
