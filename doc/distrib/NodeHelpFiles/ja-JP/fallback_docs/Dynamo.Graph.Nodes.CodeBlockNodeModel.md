## 詳細
`Code Block` により、 Dynamo で DesignScript コードをコンパクトなテキストベースの形式で直接記述でき、値の作成、計算の実行、変数の定義、ロジックの構築を行えます。`Code Block` には、単一の値、リスト、範囲、数式、文字列値、関数呼び出し、変数の代入などを含めることができます。

次の例では、`Code Block` を使用して数式を記述しています。詳細については、DesignScript ガイド(https://dynamobim.org/wp-content/links/DesignScriptGuide.pdf)を参照してください。
