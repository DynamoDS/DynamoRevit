## 詳細
`Select Geometry File Objects` は、グラフを通過させるオブジェクトを手動で選択できるようにすることで、読み込まれたジオメトリの対象範囲を絞ります。

次の例では、CAD ジオメトリを読み込み、`Select Geometry File Objects` で使用しています。ここでは、ID 16、27、33 のオブジェクトなど、特定のオブジェクトを出力対象として手動で選択しています。
