## 詳細
`Subelement.Category` は、Revit のサブ要素に割り当てられているカテゴリを取得します。サブ要素とは、レイヤ、マリオン、カーテン パネル、鉄筋、親要素内に存在し得るネストされたジオメトリなど、より大きな Revit 要素のコンポーネントまたは部品です。

次の例では、現在のビューにおけるすべての要素を選択し、サブ要素を含む要素のみが表示されるようにフィルタリングしています。次に、これらの要素を `Subelement.Category` への入力として使用します。出力は、各サブ要素に関連付けられたカテゴリのリストです。
