## 詳細
`Spacing Rule Layout` は、分割されたパス要素から間隔規則レイアウトを取得します。分割されたパスを入力として使用し、出力としては、パスに沿ってポイントをどのように配置するかをコントロールする現在の間隔規則が返されます。

次の例では、Revit モデルから分割サーフェスを選択し、そのパラメータを修正するための入力として使用しています。文字列ノードはパラメータ名「Layout」を提供し、`Spacing Rule Layout` は間隔規則タイプの値を出力します。このグラフによって、分割サーフェスのレイアウト規則が `FixedNumber` に更新されます。出力は、変更された分割サーフェス要素です。
