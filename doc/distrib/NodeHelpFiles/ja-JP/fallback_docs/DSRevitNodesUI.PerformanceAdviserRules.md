## 詳細
`Performance Adviser Rules` は、現在のセッションで使用可能な Revit のパフォーマンス アドバイザ規則を取得します。これらの規則は、モデルの健全性チェックとして機能するもので、Revit が警告やパフォーマンス上の問題を引き起こす可能性のある要素や条件を特定するために使用できます。

次の例では、[重なっている壁]と[部屋の分割線が結合されていません]を `Performance Adviser Rules` のドロップダウン メニューから選択し、リストに追加しています。このリストは、選択したパフォーマンス規則を現在のファイルに対して実行するための入力として使用され、一連のエラー メッセージや結果が返されます。その他のメニュー オプションには、[重複するインスタンス]、[ホストに含まれる挿入部品が多すぎます]、[スケッチが複雑すぎます]、[ファミリ ファイルが大きすぎます]といった規則があります。
