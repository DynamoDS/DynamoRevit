## 詳細
`Filter Geometry File Objects` は、システム間で処理されるオブジェクトのフィルタリング規則を提供します。

次の例では、North Arrows.dwg ファイルを Dynamo に読み込み、`Filter Geometry File Objects` を使用して、LayerID = 13 のオブジェクトのみが表示されるように検索をカスタマイズしています。最後のノードは、これらのプロパティを持つすべてのオブジェクトを表示します。
