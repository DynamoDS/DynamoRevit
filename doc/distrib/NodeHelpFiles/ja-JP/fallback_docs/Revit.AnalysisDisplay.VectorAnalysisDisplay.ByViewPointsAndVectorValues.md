## 詳細
`VectorAnalysisDisplay.ByViewPointsAndVectorValues` は、Revit ビューにベクトル解析表示を作成します。入力されたビューにより、解析表示の表示位置が定義されます。点により解析マーカーの位置が定義され、ベクトルにより表示される解析の方向が定義され、値により各点に関連する数値結果が定義されます。出力は、選択したビューに表示される Revit 解析表示要素です。

次の例では、2 つの点を作成して、Revit 3D ビューのサンプル位置を定義しています。次に、2 つのベクトルを作成して、それらの位置で方向解析データを定義しています。点とベクトルはリストにまとめられ、ビュー、解析名、説明とともに `VectorAnalysisDisplay.ByViewPointsAndVectorValues` への入力として使用されます。出力は、選択した Revit ビューに表示されるベクトル解析表示です。
