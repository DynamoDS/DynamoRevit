## 詳細
`AxonometricView.ByEyePointTargetAndBoundingBox` は、視点、目標位置、境界ボックス、名前、および `isolateElement` のブール値を使用して、Revit で新しいアクソメ 3D ビューを作成します。

次の例では、3D ビューの視点と目標位置を定義するために点を作成しています。また、ビューのトリミング範囲をコントロールするための境界ボックスも作成します。これらの入力は、名前およびブール値とともに `AxonometricView.ByEyePointTargetAndBoundingBox` に使用します。出力は、Revit の新しいアクソメ 3D ビューです。
