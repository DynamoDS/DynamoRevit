## 詳細
`Units` により、別のノードで `DynamoUnits.Unit` 入力を必要とする場合に使用できる、単位タイプのリストを取得できます。出力には、長さ、面積、体積、角度、および Dynamo のバージョンに応じてサポートされているその他のタイプの単位タイプが含まれます。

次の例では、`Units` で Dynamo の単位オブジェクトのリストを生成しています。これらの単位は選択またはフィルタして、`DynamoUnits.Unit` 入力を必要とするノードに渡すことができます。
