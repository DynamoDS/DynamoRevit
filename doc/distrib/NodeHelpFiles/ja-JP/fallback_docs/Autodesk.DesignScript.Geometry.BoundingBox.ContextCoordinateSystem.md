## 詳細
`BoundingBox.ContextCoordinateSystem` は、境界ボックスの方向を定義する座標系を返します。これにより Dynamo において、回転した境界ボックスやローカル基準の境界ボックスを表現できるようになります。

次の例では、ドアを選択し、そのジオメトリを使用して境界ボックスを生成しています。この境界ボックスを `BoundingBox.ContextCoordinateSystem` の入力として使用することで、座標系を取得できます。
