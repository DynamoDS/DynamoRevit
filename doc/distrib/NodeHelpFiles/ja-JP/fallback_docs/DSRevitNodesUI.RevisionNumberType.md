## 詳細
`Select Revision Number Type` により、改訂に関連するワークフローで使用する改訂番号タイプを指定できます。選択肢は[数値]、[英数字]、[なし]です。

次の例では、`Select Revision Number Type` を入力の 1 つとして使用し、改訂を作成しています。

改訂の詳細については、Revit のドキュメント(https://help.autodesk.com/view/RVT/2025/JPN/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4)を参照してください。
