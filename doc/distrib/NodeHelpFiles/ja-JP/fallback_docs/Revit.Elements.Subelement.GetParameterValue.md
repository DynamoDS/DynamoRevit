## 詳細
`Subelement.GetParameterValue` は、Revit のサブ要素からパラメータの値を取得します。

次の例では、現在のビューのすべての要素を選択し、サブ要素を含む要素のみが表示されるようにフィルタリングしています。次に、これらのサブ要素をパラメータ ID とともに `Subelement.GetParameterValue` への入力として使用します。出力は、指定されたサブ要素のパラメータ値です。
