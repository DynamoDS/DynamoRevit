## 詳細
`Import Geometry File` は、外部ジオメトリまたはモデル データを Dynamo に読み込み、それを表示、フィルタしたり、下流のワークフローで使用できるようにします。これは、サポートされている読み込み済みコンテンツをグラフに取り込むための主要なエントリ ポイントとして機能し、Dynamo が入力ファイルまたはオブジェクトを解釈して後続の処理で利用できるようにします。

次の例では、North Arrows.dwg ファイルを選択し、`Import Geometry File` の入力として使用しています。この出力により、読み込まれたファイルに含まれるすべてのジオメトリおよび関連データにアクセスできるようになります。
