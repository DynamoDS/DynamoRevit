## 詳細
`Gate` は、ブール値に基づいて入力データを通過させるかどうかをコントロールします。ゲートが開いている場合(True)、入力は出力に渡されます。ゲートが閉じている場合(False)、入力はブロックされます。

次の例では、`Gate` を使用して、グラフの実行ごとにジオメトリが分解されるのを防いでいます。ゲートが開いている場合(True)、新しく作成されたジオメトリは通過して分解されます。ゲートが閉じている場合(False)、ジオメトリはブロックされて通過せず、再度分解されることもありません。
