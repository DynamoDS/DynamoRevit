## 深入資訊
`PerspectiveView.ByEyePointAndTarget` 會使用視點、目標點、名稱和 `isolateElement`布林值，建立新的 Revit 透視 3D 視圖。

以下範例在 Dynamo 中建立 2 個點，作為相機視點和目標點。使用這些參數作為 `PerspectiveView.ByEyePointAndTarget` 的輸入，同時提供名稱和布林值。輸出是從視點看向目標點的新 Revit 透視視圖。
