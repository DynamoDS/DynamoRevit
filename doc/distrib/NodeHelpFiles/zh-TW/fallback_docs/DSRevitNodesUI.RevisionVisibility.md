## 深入資訊
`Select Revision Visibility` 提供 Revit 修訂可見性模式。選項包括 `CloudAndTagVisible`、`TagVisible` 和 `Hidden`。

以下範例使用 `Select Revision Visibility` 建立一個修訂作為其中一個輸入。

如需修訂的更多資訊，請參閱 [Revit 文件](https://help.autodesk.com/view/RVT/2025/CHT/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4)。
