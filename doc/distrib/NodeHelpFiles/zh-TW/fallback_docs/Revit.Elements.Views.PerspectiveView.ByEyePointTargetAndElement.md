## 深入資訊
`PerspectiveView.ByEyePointTargetAndElement` 會使用視點、目標點、元素、名稱和 `isolateElement`布林值，建立新的 Revit 透視 3D 視圖。

以下範例選取 Revit 元素作為透視視圖的焦點。為相機位置建立一點，為目標位置建立另一點。使用這些點作為 '`PerspectiveView.ByEyePointTargetAndElement` 的輸入，同時提供選取的元素。輸出是從視點看向目標點的新透視視圖，視圖範圍則根據選取的元素。
