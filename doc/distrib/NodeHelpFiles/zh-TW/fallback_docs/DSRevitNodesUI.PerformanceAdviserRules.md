## 深入資訊
`Performance Adviser Rules` 會擷取目前工作階段可用的 Revit 效能顧問規則。這些規則代表的是模型健全狀態檢查，Revit 可以使用這些規則識別可能造成警告或效能問題的元素或條件。

在以下範例中，從 `Performance Adviser Rules` 的下拉式功能表中選取「重疊牆」和「房間分隔線未接合」並加到清單中。然後使用此清單作為輸入，為目前檔案執行選取的效能規則，傳回一組失敗訊息/結果。其他功能表選項包括如「重複的實體」、「主體包含太多附屬件」、「草圖太複雜」和「族群檔案太大」等規則。
