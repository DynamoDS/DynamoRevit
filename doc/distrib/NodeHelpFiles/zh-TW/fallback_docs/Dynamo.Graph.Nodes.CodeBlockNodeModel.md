## 深入資訊
`Code Block` 提供一種精簡的文字格式，可直接在 Dynamo 中撰寫 DesignScript 程式碼，建立值、執行計算、定義變數和建置邏輯。`Code Block` 可以包含單一值、清單、範圍、數學表示式、字串值、函數呼叫和變數指定。

在以下範例中，`Code Block` 示範一個數學表示式。如需更多資訊，請參閱 [DesignScript 指南](https://dynamobim.org/wp-content/links/DesignScriptGuide.pdf)。
