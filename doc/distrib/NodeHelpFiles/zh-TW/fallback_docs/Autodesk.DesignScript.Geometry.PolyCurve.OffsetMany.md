## 深入資訊
`PolyCurve.OffsetMany` 會根據輸入的偏移距離和平面，將 PolyCurve 偏移為一條或多條新的 PolyCurve。

在以下範例中，`PolyCurve.ByPoints` 節點會建立 `PolyCurve.OffsetMany` 的輸入幾何圖形。帶符號的距離值 (+ 或 -) 控制偏移方向，`extendCircular` 布林值決定處理圓形邊的方式，`planeNormal` 向量定義建立偏移的平面法線方向。
