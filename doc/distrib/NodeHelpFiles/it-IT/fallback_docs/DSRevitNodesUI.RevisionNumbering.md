## In profondità
`Select Revision Numbering` fornisce il metodo di numerazione delle revisioni utilizzato nel progetto. Le revisioni possono essere numerate Per progetto o Per tavola, in base alle opzioni `PerProject` e `PerSheet`.

Nell'esempio seguente, viene creata una revisione e viene utilizzato il nodo `Select Revision Numbering` come uno degli input.

Per ulteriori informazioni sulle revisioni, vedere la [documentazione di Revit](https://help.autodesk.com/view/RVT/2025/ITA/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4).
