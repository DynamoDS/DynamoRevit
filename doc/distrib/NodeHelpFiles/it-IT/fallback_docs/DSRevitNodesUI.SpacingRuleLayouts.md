## In profondità
`Spacing Rule Layout` recupera il layout delle regole di spaziatura da un elemento del percorso diviso. Il percorso diviso viene utilizzato come input e l'output è la regola di layout di spaziatura corrente che controlla la distribuzione dei punti lungo il percorso.

Nell'esempio seguente, viene selezionata dal modello di Revit una superficie divisa che viene utilizzata come input per modificarne i parametri. Un nodo di stringa fornisce il nome di parametro "Layout", mentre `Spacing Rule Layout` fornisce il valore del tipo di regola di spaziatura. Il grafico aggiorna la regola di layout della superficie divisa a `FixedNumber`. L'output è l'elemento superficie divisa modificato.
