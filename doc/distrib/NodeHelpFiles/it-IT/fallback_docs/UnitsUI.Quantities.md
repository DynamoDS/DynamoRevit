## In profondità
`Quantities` fornisce un tipo di quantità selezionabile (ad esempio Lunghezza, Area o Volume) ed estrae le definizioni di unità associate. Queste quantità rappresentano il tipo di misurazione descritto, non il valore unitario effettivo. Ad esempio, Lunghezza è la quantità, mentre Piedi o Metri sono le unità che appartengono a tale quantità.

Nell'esempio seguente, `Quantities` viene utilizzato per selezionare un valore come Lunghezza, Area o Volume ed estrarre le definizioni di unità associate.
