## In profondità
`BoundingBox.ContextCoordinateSystem` restituisce il sistema di coordinate che definisce l'orientamento del riquadro di delimitazione, consentendo a Dynamo di rappresentare riquadri di delimitazione ruotati o orientati localmente.

Nell'esempio seguente, viene selezionata una porta e la relativa geometria viene utilizzata per generare un riquadro di delimitazione. Questo viene quindi utilizzato come input in `BoundingBox.ContextCoordinateSystem`, dove è esposto il sistema di coordinate.
