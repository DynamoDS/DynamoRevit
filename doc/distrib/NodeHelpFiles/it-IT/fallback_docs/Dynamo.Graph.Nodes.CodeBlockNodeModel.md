## In profondità
`Code Block` fornisce un formato compatto basato sul testo per la scrittura di codice DesignScript direttamente in Dynamo per creare valori, eseguire calcoli, definire variabili e creare logica. Un `Code Block` può contenere valori singoli, elenchi, intervalli, espressioni matematiche, valori di stringa, chiamate di funzione e assegnazioni di variabili.

Nell'esempio seguente, un `Code Block` dimostra un'espressione matematica. Per ulteriori informazioni, vedere la [guida di DesignScript](https://dynamobim.org/wp-content/links/DesignScriptGuide.pdf).
