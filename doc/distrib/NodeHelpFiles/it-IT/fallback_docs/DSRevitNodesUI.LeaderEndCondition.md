## In profondità
`Leader End Condition` fornisce un valore selezionabile per la condizione di fine della direttrice in Revit. Le opzioni disponibili sono Free o Attached.

Nell'esempio seguente, vengono etichettati tutti i muri della vista L1. Queste etichette vengono utilizzate con un valore Free selezionato da `Leader End Condition` come input per impostare i valori della condizione di fine della direttrice.
