## In profondità
`Mesh.BoundingBox` restituisce il riquadro di delimitazione di una determinata mesh.

Nell'esempio seguente, vengono generati i punti che vengono utilizzati per creare una mesh, che è poi utilizzata come input in `Mesh.BoundingBox`. L'output è un riquadro di delimitazione utilizzato per estrarre `MinPoint`.
