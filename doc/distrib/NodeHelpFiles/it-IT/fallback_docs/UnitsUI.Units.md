## In profondità
`Units` fornisce un elenco di tipi di unità disponibili per l'utilizzo quando un altro nodo richiede un input `DynamoUnits.Unit`. L'output include tipi di unità quali lunghezza, area, volume, angolo e altri tipi supportati a seconda della versione di Dynamo.

Nell'esempio seguente, `Units` genera un elenco di oggetti unità di Dynamo. Queste unità possono quindi essere selezionate o filtrate e trasmesse ai nodi che richiedono un input `DynamoUnits.Unit`.
