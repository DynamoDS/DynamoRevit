## In profondità
`Select Revision Number Type` fornisce un tipo di numerazione delle revisioni da utilizzare nei workflow correlati alle revisioni. Le opzioni disponibili sono Numerica, Alfanumerica o Nessuna.

Nell'esempio seguente, viene creata una revisione e viene utilizzato il nodo `Select Revision Number Type` come uno degli input.

Per ulteriori informazioni sulle revisioni, vedere la [documentazione di Revit](https://help.autodesk.com/view/RVT/2025/ITA/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4).
