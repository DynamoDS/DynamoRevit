## In profondità
`Select Geometry File Objects` restringe l'ambito della geometria importata, consentendo di selezionare manualmente quali oggetti devono essere inseriti nel grafico.

Nell'esempio seguente, viene importata la geometria CAD che viene utilizzata in `Select Geometry File Objects`. Vengono selezionati manualmente per l'output oggetti specifici, ad esempio gli oggetti con ID 16, 27 e 33 mostrati qui.
