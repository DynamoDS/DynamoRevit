## In profondità
`Symbols` fornisce un elenco selezionabile di simboli di unità che Dynamo può utilizzare durante la formattazione o l'analisi di valori basati sulle unità.

Nell'esempio seguente, `Symbols` viene utilizzato per selezionare un simbolo di unità dalla libreria di simboli di unità disponibile di Dynamo. L'output è un oggetto `DynamoUnits.Symbol` che può essere utilizzato come input durante la formattazione di valori frazionari.
