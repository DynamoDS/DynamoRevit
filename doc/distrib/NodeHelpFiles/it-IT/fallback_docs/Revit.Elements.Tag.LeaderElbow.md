## In profondità
`Tag.LeaderElbow` restituisce il punto di curvatura della linea direttrice di un'etichetta. L'input è un elemento etichetta di Revit e l'output è un punto di Dynamo che rappresenta la posizione del gomito della direttrice.

Nell'esempio seguente, viene selezionata un'etichetta dalla vista di Revit attiva che viene utilizzata come input per `Tag.LeaderElbow`. L'output è la posizione del punto in cui si piega ogni direttrice dell'etichetta.
