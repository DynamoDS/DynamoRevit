## In profondità
`PolyCurve.OffsetMany` esegue l'offset di una PolyCurve in una o più nuove PolyCurve in base al piano e alla distanza di offset di input.

Nell'esempio seguente, un nodo `PolyCurve.ByPoints` crea la geometria di input per`PolyCurve.OffsetMany`. Un valore di distanza con segno (+ o -) controlla la direzione dell'offset, un valore booleano `extendCircular` determina la modalità di gestione dei bordi circolari e un vettore `planeNormal` definisce la direzione normale del piano in cui viene creato l'offset.
