## In profondità
`Materials` consente di selezionare un singolo elemento materiale da un elenco alfabetico di tutti gli elementi materiale nel documento (ossia il file) corrente.

Il materiale selezionato può essere utilizzato come input di nodi quali `Element.SetParameterByName`, per assegnare un materiale al parametro materiale di un elemento, o `Material` per eseguire query sulle relative proprietà.
