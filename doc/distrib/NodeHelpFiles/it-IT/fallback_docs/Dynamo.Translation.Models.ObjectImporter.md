## In profondità
`Import Geometry File` importa in Dynamo la geometria esterna o i dati del modello in modo che possano essere visualizzati, filtrati o utilizzati nei workflow a valle. Funge da punto di ingresso principale per inserire nel grafico il contenuto importato supportato, consentendo a Dynamo di interpretare il file o l'oggetto in entrata e di renderlo disponibile per un'ulteriore elaborazione.

Nell'esempio seguente, viene selezionato il file North Arrows.dwg che viene utilizzato come input per `Import Geometry File`. L'output consente di accedere a tutta la geometria e ai dati associati contenuti nel file importato.
