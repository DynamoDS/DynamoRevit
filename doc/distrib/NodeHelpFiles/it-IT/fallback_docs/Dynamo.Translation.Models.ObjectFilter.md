## In profondità
`Filter Geometry File Objects` fornisce regole di filtraggio per gli oggetti in fase di elaborazione tra i sistemi.

Nell'esempio seguente, viene importato in Dynamo il file North Arrows.dwg e viene utilizzato il nodo `Filter Geometry File Objects` per personalizzare la ricerca in modo da mostrare solo gli oggetti in cui LayerID = 13. L'ultimo nodo visualizza tutti gli oggetti con tali proprietà.
