## In profondità
`Remember` memorizza un valore nel file di Dynamo in modo che possa essere richiamato successivamente dal grafico, anche quando l'input è null. È utile per conservare i dati tra un'esecuzione e l'altra, mantenere lo stato o fare riferimento a informazioni memorizzate in precedenza senza ricrearle ogni volta.

Nell'esempio seguente, viene selezionato un singolo piano e la geometria viene estratta e utilizzata come input per `Remember`. Il risultato memorizzato è quindi disponibile come output per essere riutilizzato nel grafico.
