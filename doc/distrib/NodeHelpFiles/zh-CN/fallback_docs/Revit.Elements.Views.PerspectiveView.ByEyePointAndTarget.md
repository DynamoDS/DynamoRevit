## 详细
“PerspectiveView.ByEyePointAndTarget”使用视点、目标点、名称和“isolateElement”布尔值创建新的 Revit 透视三维视图。

在下面的示例中，在 Dynamo 中创建了 2 个点，并将其用作相机视点和目标点。这些与名称和布尔值一起用作“PerspectiveView.ByEyePointAndTarget”的输入。输出是一个新的 Revit 透视视图，从视点朝向目标点。
