## 详细
"Select Revision Number Type"提供修订编号类型，用于与修订相关的工作流。可选择数字、字母数字或无。

在下述示例中，创建新修订并使用“Select Revision Number Type”作为输入之一。

有关修订的详细信息，请参见 [Revit 文档](https://help.autodesk.com/view/RVT/2025/CHS/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4)。
