## 详细
“PerspectiveView.ByEyePointTargetAndElement”使用视点、目标点、图元、名称和“isolateElement”布尔值创建新的 Revit 透视三维视图。

在下面的示例中，选择了 Revit 图元并将其用作透视视图的焦点。系统将为相机位置创建一个点，并为目标位置创建另一个点。这些变量与选定图元一起用作“PerspectiveView.ByEyePointTargetAndElement”的输入。输出是一个新的透视视图，该视图从视点朝向目标点，其视图范围基于选定图元。
