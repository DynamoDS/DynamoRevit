## 详细
“Code Block”提供了一种基于文本的紧凑格式，用于直接在 Dynamo 中编写 DesignScript 代码，以创建值、执行计算、定义变量和构建逻辑。“Code Block”可以包含单个值、列表、范围、数学表达式、字符串值、函数调用和变量赋值。

在下面的示例中，“Code Block”演示了数学表达式。有关详细信息，请参见 [DesignScript 手册](https://dynamobim.org/wp-content/links/DesignScriptGuide.pdf)。
