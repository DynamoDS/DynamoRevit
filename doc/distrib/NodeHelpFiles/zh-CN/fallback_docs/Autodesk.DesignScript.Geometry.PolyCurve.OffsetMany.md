## 详细
“PolyCurve.OffsetMany”根据输入偏移距离和平面，将一条 PolyCurve 偏移为一条或多条新的 PolyCurve。

在下面的示例中，“PolyCurve.ByPoints”节点为“PolyCurve.OffsetMany”创建输入几何图形。带符号距离值(+ 或 -)控制偏移方向，“extendCircular”布尔值确定如何处理圆形边，“planeNormal”向量定义在其中创建偏移的平面的法线方向。
