## 详细
“PerspectiveView.ByEyePointTargetAndBoundingBox”使用视点、目标点、边界框、名称和“isolateElement”布尔值创建新的 Revit 透视三维视图。

在下面的示例中，将创建点来定义三维视图的视点和目标位置。还会创建边界框以控制视图的裁剪范围。这些输入与“PerspectiveView.ByEyePointTargetAndBoundingBox”以及名称和布尔值一起使用。输出是 Revit 中的新透视三维视图。
