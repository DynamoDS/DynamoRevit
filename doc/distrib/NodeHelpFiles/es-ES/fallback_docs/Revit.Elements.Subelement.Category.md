## En detalle:
`Subelement.Category` recupera la categoría asignada a un subelemento de Revit. Los subelementos son componentes o partes de un elemento de Revit de mayor tamaño, como capas, montantes, paneles de muro cortina, armaduras o geometría anidada que pueden encontrarse dentro de un elemento principal.

En el ejemplo siguiente, se seleccionan todos los elementos de la vista actual y se filtran para mostrar solo aquellos que contienen subelementos. A continuación, los subelementos se utilizan como entrada para `Subelement.Category`. El resultado es una lista de categorías asociadas a cada subelemento.
