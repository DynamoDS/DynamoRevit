## En detalle:
`Filter Geometry File Objects` proporciona reglas de filtrado para los objetos que se procesan entre sistemas.

En el ejemplo siguiente, se importa el archivo North Arrows.dwg a Dynamo y se utiliza `Filter Geometry File Objects` para personalizar la búsqueda de modo que solo se muestren los objetos en los que LayerID = 13. El último nodo muestra todos los objetos con esas propiedades.
