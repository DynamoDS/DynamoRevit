## En detalle:
`Select Geometry File Objects` restringe el ámbito de la geometría importada al permitir la selección manual de los objetos que se pasan a través del gráfico.

En el ejemplo siguiente, se importa geometría CAD y se utiliza en `Select Geometry File Objects`. Los objetos específicos se seleccionan manualmente para la salida, como los objetos con ID 16, 27 y 33 que se muestran aquí.
