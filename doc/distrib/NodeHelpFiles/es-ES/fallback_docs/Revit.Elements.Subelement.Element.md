## En detalle:
`Subelement.Element` devuelve el elemento principal de Revit al que pertenece un determinado subelemento.

En el ejemplo siguiente, se seleccionan todos los elementos de la vista actual y se filtran para mostrar solo aquellos que contienen subelementos. A continuación, los subelementos se utilizan como entrada para `Subelement.Element`. El resultado es una lista de elementos principales asociados a cada subelemento.
