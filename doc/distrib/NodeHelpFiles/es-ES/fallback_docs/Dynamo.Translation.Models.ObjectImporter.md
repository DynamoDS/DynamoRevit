## En detalle:
`Import Geometry File` importa datos de modelo o geometría externa en Dynamo para que se puedan ver, filtrar o utilizar en flujos de trabajo posteriores. Actúa como el punto de entrada principal para incorporar contenido importado admitido en el gráfico, lo que permite a Dynamo interpretar el archivo u objeto entrantes y mostrarlo para su procesamiento posterior.

En el ejemplo siguiente, se selecciona el archivo North Arrows.dwg y se utiliza como entrada para `Import Geometry File`. El resultado permite acceder a toda la geometría y a los datos asociados que contiene el archivo importado.
