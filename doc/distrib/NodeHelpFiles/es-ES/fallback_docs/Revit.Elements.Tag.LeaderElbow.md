## En detalle:
`Tag.LeaderElbow` devuelve el punto de plegado de la línea directriz de una etiqueta. La entrada es un elemento de etiqueta de Revit y la salida es un punto de Dynamo que representa la ubicación del codo de la directriz.

En el ejemplo siguiente, se selecciona una etiqueta de la vista activa de Revit y se utiliza como entrada para `Tag.LeaderElbow`. La salida es la ubicación del punto donde se pliega cada directriz de etiqueta.
