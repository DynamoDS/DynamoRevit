## En detalle:
`FilterRule.ByRuleType` crea una regla de filtrado de Revit basada en el tipo de regla, el parámetro y el valor de comparación seleccionados.

En el ejemplo siguiente, se identifica un tipo de muro y se utiliza el parámetro `Fire Rating` como entrada para `FilterRule.ByRuleType`, junto con un valor y un tipo de regla. El resultado es una regla de filtrado que se aplica posteriormente a una vista.
