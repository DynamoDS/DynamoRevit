## En detalle:
`Mesh.BoundingBox` devuelve el cuadro delimitador de la malla especificada.

En el ejemplo siguiente, se generan puntos que se utilizan para crear una malla, que posteriormente se emplea como entrada para `Mesh.BoundingBox`. El resultado es un cuadro delimitador que se utiliza para extraer el `MinPoint`.
