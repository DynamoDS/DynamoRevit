## En detalle:
`Quantities` proporciona un tipo de cantidad seleccionable (como longitud, área o volumen) y extrae las definiciones de unidad asociadas. Estas cantidades representan el tipo de medida que se describe, no el valor real de unidad. Por ejemplo, "Length" es la cantidad, mientras que "Feet" o "Meters" son unidades que pertenecen a esa cantidad.

En el ejemplo siguiente, se utiliza `Quantities` para seleccionar un valor como, por ejemplo, longitud, área o volumen y extraer las definiciones de unidad asociadas.
