## En detalle:
`Code Block` proporciona un formato compacto basado en texto para escribir código DesignScript directamente en Dynamo a fin de crear valores, realizar cálculos, definir variables y generar lógica.`Code Block` puede contener valores únicos, listas, rangos, expresiones matemáticas, valores de cadena, llamadas a funciones y asignaciones de variables.

En el ejemplo siguiente, `Code Block` muestra una expresión matemática. Para obtener más información, consulte la [Guía de DesignScript](https://dynamobim.org/wp-content/links/DesignScriptGuide.pdf)
