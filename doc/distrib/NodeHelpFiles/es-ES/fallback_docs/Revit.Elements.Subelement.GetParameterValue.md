## En detalle:
`Subelement.GetParameterValue` recupera el valor de un parámetro de un subelemento de Revit.

En el ejemplo siguiente, se seleccionan todos los elementos de la vista actual y se filtran para mostrar solo aquellos que contienen subelementos. A continuación, los subelementos se utilizan como entrada para `Subelement.GetParameterValue`, junto con los ID de parámetro. El resultado es el valor del parámetro correspondiente al subelemento especificado.
