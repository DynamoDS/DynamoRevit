## En detalle:
`SelectRevision Visibility` ofrece un modo de visibilidad de revisiones de Revit. Las opciones son `CloudAndTagVisible`, `TagVisible` y `Hidden`.

En el ejemplo siguiente, se crea una revisión con `Select Revision Visibility` como una de las entradas.

Para obtener más información sobre las revisiones, consulte la [documentación de Revit](https://help.autodesk.com/view/RVT/2025/ESP/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4).
