## En detalle:
`BoundingBox.ContextCoordinateSystem` devuelve el sistema de coordenadas que define la orientación del cuadro delimitador, lo que permite a Dynamo representar cuadros delimitadores girados u orientados localmente.

En el ejemplo siguiente, se selecciona una puerta y se utiliza su geometría para generar un rectángulo delimitador. A continuación, este se utiliza como entrada para `BoundingBox.ContextCoordinateSystem`, donde se muestra el sistema de coordenadas.
