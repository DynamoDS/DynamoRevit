## Em profundidade
`PerspectiveView.ByEyePointTargetAndBoundingBox` cria uma nova vista 3D em perspectiva no Revit usando um ponto de vista, um ponto de destino, uma caixa delimitadora, um nome e um valor booleano `isolateElement`.

No exemplo abaixo, são criados os pontos para definir o ponto de vista e a localização de destino para a vista 3D. Também é criada uma caixa delimitadora para controlar as extensões de recorte da vista. Essas entradas são usadas com `PerspectiveView.ByEyePointTargetAndBoundingBox` junto com um nome e um valor booleano. A saída é uma nova vista 3D em perspectiva no Revit.
