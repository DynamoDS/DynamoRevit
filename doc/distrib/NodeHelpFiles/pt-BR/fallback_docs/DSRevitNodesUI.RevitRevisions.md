## Em profundidade
`Select Revision` fornece uma forma de selecionar uma revisão do projeto atual do Revit.

No exemplo abaixo, é usado `Select Revision` com “Seq. 1 — Projeto esquemático” selecionado. A saída é então usada como entrada para recuperar a data da revisão e o status de emissão.

Para obter mais informações sobre as revisões, consulte a [documentação do Revit](https://help.autodesk.com/view/RVT/2025/PTB/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4).
