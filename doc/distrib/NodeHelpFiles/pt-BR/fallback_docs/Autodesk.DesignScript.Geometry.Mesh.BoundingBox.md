## Em profundidade
`Mesh.BoundingBox` retorna a caixa delimitadora de uma determinada malha.

No exemplo abaixo, são gerados os pontos e usados para criar uma malha, que é usada como entrada para `Mesh.BoundingBox`. A saída é uma caixa delimitadora usada para extrair o `MinPoint`.
