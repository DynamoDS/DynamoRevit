## Em profundidade
`FilterRule.ByRuleType` cria uma regra de filtro do Revit com base em um tipo de regra, parâmetro e valor de comparação selecionados.

No exemplo abaixo, é identificado um tipo de parede, e o parâmetro `Fire Rating` é usado como uma entrada para `FilterRule.ByRuleType` junto com um valor e um tipo de regra. A saída é uma regra de filtro que é aplicada a uma vista.
