## Em profundidade
`Select Revision Numbering` fornece o método de numeração de revisão usado no projeto. As revisões podem ser numeradas Por projeto ou Por folha, correspondendo às opções `PerProject` e `PerSheet`.

No exemplo abaixo, é criada uma revisão e `Select Revision Numbering` é usado como uma das entradas.

Para obter mais informações sobre as revisões, consulte a [documentação do Revit](https://help.autodesk.com/view/RVT/2025/PTB/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4).
