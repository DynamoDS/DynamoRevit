## Em profundidade
`Code Block` fornece um formato compacto baseado em texto para gravar código do DesignScript diretamente no Dynamo para criar valores, executar cálculos, definir variáveis e criar lógica. Um `Code Block` pode conter valores únicos, listas, intervalos, expressões matemáticas, valores de sequência de caracteres, chamadas de função e atribuições de variáveis.

No exemplo abaixo, um `Code Block` demonstra uma expressão matemática. Para obter mais informações, consulte o [Guia do DesignScript](https://dynamobim.org/wp-content/links/DesignScriptGuide.pdf).
