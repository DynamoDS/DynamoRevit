## Em profundidade
`Select Revision Visibility` fornece um modo de visibilidade de revisão do Revit. As opções são `CloudAndTagVisible`, `TagVisible` e `Hidden`.

No exemplo abaixo, é criada uma revisão usando `Select Revision Visibility` como uma das entradas.

Para obter mais informações sobre as revisões, consulte a [documentação do Revit](https://help.autodesk.com/view/RVT/2025/PTB/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4).
