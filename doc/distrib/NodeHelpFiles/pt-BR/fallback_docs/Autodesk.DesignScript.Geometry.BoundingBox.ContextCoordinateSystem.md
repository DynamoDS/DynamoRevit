## Em profundidade
`BoundingBox.ContextCoordinateSystem` retorna o sistema de coordenadas que define a orientação da caixa delimitadora, permitindo que o Dynamo represente caixas delimitadoras rotacionadas ou orientadas localmente.

No exemplo abaixo, é selecionada uma porta e sua geometria é usada para gerar uma caixa delimitadora. Isso é usado como entrada para `BoundingBox.ContextCoordinateSystem`, onde o sistema de coordenadas é exposto.
