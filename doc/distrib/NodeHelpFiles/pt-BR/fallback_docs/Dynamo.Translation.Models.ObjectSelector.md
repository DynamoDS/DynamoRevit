## Em profundidade
`Select Geometry File Objects` restringe o escopo da geometria importada ativando a seleção manual de quais objetos são passados pelo gráfico.

No exemplo abaixo, é importada a geometria CAD e usada em `Select Geometry File Objects`. Objetos específicos são selecionados manualmente para a saída, como os objetos com IDs 16, 27 e 33 mostrados aqui.
