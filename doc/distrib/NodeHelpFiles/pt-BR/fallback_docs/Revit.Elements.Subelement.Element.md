## Em profundidade
`Subelement.Element` retorna o elemento principal do Revit ao qual um determinado subelemento pertence.

No exemplo abaixo, são selecionados todos os elementos na vista atual e filtrados para mostrar somente os elementos que contêm subelementos. Em seguida, os subelementos são usados como entrada para `Subelement.Element`. A saída é uma lista de elementos principais associados a cada subelemento.
