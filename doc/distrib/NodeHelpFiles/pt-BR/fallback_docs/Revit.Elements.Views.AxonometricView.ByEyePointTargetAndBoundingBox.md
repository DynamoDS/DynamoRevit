## Em profundidade
`AxonometricView.ByEyePointTargetAndBoundingBox` cria uma nova vista 3D axonométrica no Revit usando um ponto de vista, um ponto de destino, uma caixa delimitadora, um nome e um valor booleano `isolateElement`.

No exemplo abaixo, são criados os pontos para definir o ponto de vista e a localização de destino para a vista 3D. Uma caixa delimitadora também é criada para controlar as extensões de recorte da vista. Essas entradas são usadas com `AxonometricView.ByEyePointTargetAndBoundingBox` junto com um nome e um valor booleano. A saída é uma nova vista 3D axonométrica no Revit.
