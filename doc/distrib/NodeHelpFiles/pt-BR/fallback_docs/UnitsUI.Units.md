## Em profundidade
`Units` fornece uma lista de tipos de unidade disponíveis para uso quando outro nó requer uma entrada `DynamoUnits.Unit`. A saída inclui tipos de unidade como comprimento, área, volume, ângulo e outros tipos compatíveis, dependendo da versão do Dynamo.

No exemplo abaixo, `Units` gera uma lista de objetos de unidade do Dynamo. Essas unidades podem ser selecionadas ou filtradas e passadas para nós que exigem uma entrada `DynamoUnits.Unit`.
