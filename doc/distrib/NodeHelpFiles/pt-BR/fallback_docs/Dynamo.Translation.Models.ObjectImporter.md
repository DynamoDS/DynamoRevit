## Em profundidade
`Import Geometry File` importa a geometria externa ou os dados do modelo para o Dynamo para que possam ser visualizados, filtrados ou usados em fluxos de trabalho a jusante. Ele atua como o principal ponto de entrada para trazer o conteúdo importado compatível para o gráfico, permitindo que o Dynamo interprete o arquivo ou objeto de entrada e o exponha para processamento adicional.

No exemplo abaixo, é selecionado o arquivo North Arrows.dwg e usado como entrada para `Import Geometry File`. A saída fornece acesso a todas as geometrias e dados associados contidos no arquivo importado.
