## Em profundidade
`Filter Geometry File Objects` fornece regras de filtragem para objetos que estão sendo processados entre sistemas.

No exemplo abaixo, é importado o arquivo North Arrows.dwg para o Dynamo e `Filter Geometry File Objects` é usado para personalizar a pesquisa para mostrar somente objetos em que LayerID = 13. O último nó exibe todos os objetos com essas propriedades.
