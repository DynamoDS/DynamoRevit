## Em profundidade
`Select Revision Number Type` fornece um tipo de numeração de revisão para uso em fluxos de trabalho relacionados a revisões. As escolhas são Numérico, Alfanumérico ou Nenhum.

No exemplo abaixo, é criada uma revisão e `Select Revision Number Type` é usado como uma das entradas.

Para obter mais informações sobre as revisões, consulte a [documentação do Revit](https://help.autodesk.com/view/RVT/2025/PTB/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4).
