## Em profundidade
`Spacing Rule Layout` recupera o layout da regra de espaçamento de um elemento de caminho dividido. O caminho dividido é usado como entrada, e a saída é a regra de layout de espaçamento atual que controla como os pontos são distribuídos ao longo do caminho.

No exemplo abaixo, é selecionada uma superfície dividida no modelo do Revit e usada como entrada para modificar seus parâmetros. Um nó de sequência de caracteres fornece o nome do parâmetro “Layout”, enquanto `Spacing Rule Layout` fornece o valor do tipo de regra de espaçamento. O gráfico atualiza a regra de layout da superfície dividida para `FixedNumber`. A saída é o elemento de superfície dividida modificado.
