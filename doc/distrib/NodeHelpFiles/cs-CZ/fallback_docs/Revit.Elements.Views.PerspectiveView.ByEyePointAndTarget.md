## Podrobnosti
Uzel `PerspectiveView.ByEyePointAndTarget` vytvoří nový perspektivní 3D pohled aplikace Revit pomocí bodu oka, cílového bodu, názvu a booleovské hodnoty `isolateElement`.

V níže uvedeném příkladu jsou v aplikaci Dynamo vytvořeny dva body, které se použijí jako bod oka kamery a cílový bod. Používají se jako vstupy uzlu `PerspectiveView.ByEyePointAndTarget` společně s názvem a booleovskou hodnotou. Výstupem je nový perspektivní pohled aplikace Revit, který je orientovaný z bodu oka směrem k cílovému bodu.
