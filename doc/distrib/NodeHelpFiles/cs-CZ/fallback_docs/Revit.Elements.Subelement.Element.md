## Podrobnosti
Uzel `Subelement.Element` vrátí nadřazený prvek aplikace Revit, ke kterému patří daný dílčí prvek.

V níže uvedeném příkladu jsou vybrány a filtrovány všechny prvky v aktuálním pohledu tak, aby se zobrazily pouze prvky, které obsahují dílčí prvky. Dílčí prvky se poté použijí jako vstup pro uzel `Subelement.Element`. Výstupem je seznam nadřazených prvků asociovaných s jednotlivými dílčími prvky.
