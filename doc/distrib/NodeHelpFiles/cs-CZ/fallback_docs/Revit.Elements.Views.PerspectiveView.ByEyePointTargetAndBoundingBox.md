## Podrobnosti
Uzel `PerspectiveView.ByEyePointTargetAndBoundingBox` vytvoří nový perspektivní 3D pohled aplikace Revit pomocí bodu oka, cílového bodu, ohraničujícího kvádru, názvu a booleovské hodnoty `isolateElement`.

V níže uvedeném příkladu jsou vytvořeny body, které definují bod oka a cílové umístění pro 3D pohled. Vytvoří se také ohraničující kvádr, který bude řídit rozsah ořezání pohledu. Tyto vstupy se používají společně s uzlem `PerspectiveView.ByEyePointTargetAndBoundingBox` společně s názvem a booleovskou hodnotou. Výstupem je nový perspektivní 3D pohled v aplikaci Revit.
