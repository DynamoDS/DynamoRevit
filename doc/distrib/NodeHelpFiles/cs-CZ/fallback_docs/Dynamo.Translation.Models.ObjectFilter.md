## Podrobnosti
Uzel `Filter Geometry File Objects` poskytne pravidla filtrování pro objekty zpracovávané mezi systémy.

V níže uvedeném příkladu je soubor North Arrows.dwg importován do aplikace Dynamo a pomocí uzlu `Filter Geometry File Objects` je přizpůsobeno vyhledávání tak, aby se zobrazovaly pouze objekty s ID hladiny = 13. Poslední uzel zobrazí všechny objekty s těmito vlastnostmi.
