## Podrobnosti
Uzel `Tag.LeaderElbow` vrátí bod ohybu odkazové čáry popisku. Vstupem je prvek popisku aplikace Revit a výstupem je bod aplikace Dynamo představující umístění ohybu odkazové čáry.

V níže uvedeném příkladu je v aktivním pohledu aplikace Revit vybrán popisek a použije se jako vstup pro uzel `Tag.LeaderElbow`. Výstupem je umístění bodu, kde se ohýbají jednotlivé odkazové čáry popisků.
