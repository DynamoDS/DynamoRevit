## Podrobnosti
Možnost `Gate` určí, zda mohou vstupní data procházet na základě booleovské hodnoty. Pokud je brána otevřená (True), vstup se předá výstupu. Pokud je brána zavřená (False), vstup je zablokován.

V níže uvedeném příkladu se pomocí možnosti `Gate` zabrání rozložení geometrie při každém spuštění grafu. Když je brána otevřená (True), nově vytvořená geometrie prochází a rozloží se. Když je brána zavřená (False), geometrie je zablokována a nebude předána ani znovu rozložena.
