## Podrobnosti
Uzel `Subelement.GetParameterValue` načte hodnotu parametru z dílčího prvku aplikace Revit.

V níže uvedeném příkladu jsou vybrány a filtrovány všechny prvky v aktuálním pohledu tak, aby se zobrazily pouze prvky, které obsahují dílčí prvky. Dílčí prvky se pak použijí jako vstup pro uzel `Subelement.GetParameterValue` společně s ID parametrů. Výstupem je hodnota parametru z daného dílčího prvku.
