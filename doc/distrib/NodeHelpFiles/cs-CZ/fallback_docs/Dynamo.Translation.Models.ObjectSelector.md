## Podrobnosti
Uzel `Select Geometry File Objects` zúží rozsah importované geometrie tím, že umožní ruční výběr objektů, které procházejí grafem.

V níže uvedeném příkladu je geometrie CAD importována a použita v uzlu `Select Geometry File Objects`. Specifické objekty jsou vybrány ručně pro výstup, například objekty s ID 16, 27 a 33 zobrazené zde.
