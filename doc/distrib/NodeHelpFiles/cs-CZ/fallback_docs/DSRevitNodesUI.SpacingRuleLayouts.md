## Podrobnosti
Uzel `Spacing Rule Layout` načte rozvržení pravidla rozestupu z prvku rozdělené trajektorie. Rozdělená trajektorie se použije jako vstup a výstupem je aktuální pravidlo rozvržení rozestupu, které řídí, jak jsou body podél trajektorie distribuovány.

V níže uvedeném příkladu je z modelu aplikace Revit vybrán rozdělený povrch a použije se jako vstup pro úpravu jeho parametrů. Uzel řetězce poskytuje název parametru Rozvržení, zatímco uzel `Spacing Rule Layout` poskytuje hodnotu typu pravidla rozestupu. Graf aktualizuje pravidlo rozvržení rozděleného povrchu na hodnotu `FixedNumber`. Výstupem je upravený prvek rozděleného povrchu.
