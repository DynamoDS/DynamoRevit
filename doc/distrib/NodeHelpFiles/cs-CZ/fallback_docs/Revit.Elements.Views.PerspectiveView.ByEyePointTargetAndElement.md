## Podrobnosti
Uzel `PerspectiveView.ByEyePointTargetAndElement` vytvoří nový perspektivní 3D pohled aplikace Revit pomocí bodu oka, cílového bodu, prvku, názvu a booleovské hodnoty `isolateElement`.

V níže uvedeném příkladu je vybrán prvek aplikace Revit a používá se jako ohnisko perspektivního pohledu. Vytvoří se bod pro umístění kamery a další bod pro umístění cíle. Ty se používají jako vstupy uzlu `PerspectiveView.ByEyePointTargetAndElement` společně s vybraným prvkem. Výstupem je nový perspektivní pohled z bodu oka směrem k cílovému bodu, přičemž rozsah pohledu je založen na vybraném prvku.
