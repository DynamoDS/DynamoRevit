## Podrobnosti
Uzel `Subelement.GetAllParameters` načte vnitřní ID parametrů aplikace Revit dílčích prvků, nikoli zobrazované názvy parametrů.

V níže uvedeném příkladu jsou vybrány a filtrovány všechny prvky v aktuálním pohledu tak, aby se zobrazily pouze prvky, které obsahují dílčí prvky. Dílčí prvky se pak použijí jako vstup pro uzel `Subelement.GetAllParameters`. Výstupem je seznam ID parametrů asociovaných s jednotlivými dílčími prvky. Poslední uzel zobrazuje výstup použitý k získání hodnot parametrů.
