## Podrobnosti
Uzel `Mesh.BoundingBox` vrátí ohraničující kvádr dané sítě.

V následujícím příkladu jsou vygenerovány body a použijí se k vytvoření sítě, která se pak použije jako vstup uzlu `Mesh.BoundingBox`. Výstupem je ohraničující kvádr použitý k extrahování hodnoty `MinPoint`.
