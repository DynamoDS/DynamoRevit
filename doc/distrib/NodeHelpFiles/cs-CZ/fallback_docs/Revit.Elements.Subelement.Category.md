## Podrobnosti
Uzel `Subelement.Category` načte kategorii přiřazenou k dílčímu prvku aplikace Revit. Dílčí prvky jsou komponenty nebo součásti většího prvku aplikace Revit, například hladin, příčlí, panelů obvodového pláště, výztuží nebo vnořené geometrie, které mohou existovat v rámci nadřazeného prvku.

V níže uvedeném příkladu jsou vybrány a filtrovány všechny prvky v aktuálním pohledu tak, aby se zobrazily pouze prvky, které obsahují dílčí prvky. Dílčí prvky se poté použijí jako vstup pro uzel `Subelement.Category`. Výstupem je seznam kategorií asociovaných s jednotlivými dílčími prvky.
