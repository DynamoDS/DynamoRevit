## Подробности
Узел `Spacing Rule Layout` извлекает компоновку правила расстановки интервалов из элемента разделенной траектории. Разделенная траектория используется в качестве входных данных, а на выходе получается текущее правило компоновки интервалов, которое управляет распределением точек вдоль траектории.

В приведенном ниже примере разделенная поверхность выбирается из модели Revit и используется в качестве входных данных для изменения ее параметров. Узел String предоставляет имя параметра Layout, а `Spacing Rule Layout` — значение типа правила расстановки интервалов. Граф меняет правило компоновки разделенной поверхности на значение, выраженное элементом `FixedNumber`. На выходе получается измененный элемент разделенной поверхности.
