## Подробности
Узел `Performance Adviser Rules` возвращает правила Консультанта по производительности Revit, доступные в рамках текущего сеанса. Эти правила относятся к проверке работоспособности модели, которая позволяет программе Revit выявлять элементы или условия, являющиеся причиной предупреждений или проблем с производительностью.

В приведенном ниже примере показано, как выбрать варианты «Перекрывающиеся стены» и «Линия-разделитель помещений является несоединенной» в раскрывающемся меню `Performance Adviser Rules` и добавить в список. Затем этот список используется в качестве входных данных при применении выбранных правил Консультанта по производительности к текущему файлу; возвращается набор результатов и сообщений об ошибках. Другие параметры меню включают такие правила, как «Дублирующиеся экземпляры», «Объект-основа содержит слишком много вставок», «Слишком сложный эскиз» и «Слишком большой файл семейства».
