## Подробности
Узел `Transaction.Start` запускает транзакцию в текущем документе Revit. Транзакции используются для группирования изменений, внесенных в модель Revit, чтобы их можно было внести или откатить вместе. Узлы `Transaction.Start` и `Transaction.End` обычно используются вместе, если рабочему процессу Dynamo требуется точно контролировать, когда начинают и заканчивают вноситься изменения в документ Revit.

В приведенном ниже примере создается уровень, который используется в качестве входных данных для узла `Transaction.Start`. При этом будет запущена транзакция Revit до внесения изменений в модель. После завершения всех необходимых операций в Revit узел `Transaction.End` закрывает транзакцию и вносит изменения в документ. На выходе получается объект транзакции, который можно передать другим узлам, связанным с транзакцией.
