## Подробности
Узел `Subelement.Category` извлекает категорию, назначенную подэлементу Revit. Подэлементы — это компоненты или части более крупного элемента Revit, например слои, импосты, панели витража, арматурные стержни или объекты вложенной геометрии, которые могут существовать в родительском элементе.

В приведенном ниже примере выбираются все элементы на текущем виде и фильтруются для отображения только элементов, содержащих подэлементы. Затем подэлементы используются в качестве входных данных для узла `Subelement.Category`. На выходе получается список категорий, связанных с каждым подэлементом.
