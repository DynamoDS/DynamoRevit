## Подробности
Узел `PerspectiveView.ByEyePointTargetAndBoundingBox` создает 3D-вид Revit в перспективе, используя точку обзора, целевую точку, ограничивающую рамку, имя и логическое значение `isolateElement`.

В приведенном ниже примере создаются точки, определяющие точку обзора и целевое положение для 3D-вида. Для управления границами обрезки вида также создается ограничивающая рамка. Эти входные данные используются для узла `PerspectiveView.ByEyePointTargetAndBoundingBox` вместе с именем и логическим значением. На выходе получается новый 3D-вид Revit в перспективе.
