## Подробности
Узел `FilterRule.ByRuleType` создает правило фильтрации Revit на основе выбранного типа правила, параметра и значения сравнения.

В приведенном ниже примере определяется тип стены, а параметр `Fire Rating` используется в качестве входных данных для узла `FilterRule.ByRuleType` вместе со значением и типом правила. На выходе получается правило фильтрации, которое затем применяется к виду.
