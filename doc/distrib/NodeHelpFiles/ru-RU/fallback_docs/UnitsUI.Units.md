## Подробности
Узел `Units` предоставляет список доступных типов единиц измерения, которые можно использовать, когда другому узлу требуется входной параметр `DynamoUnits.Unit`. На выходе получаются типы единиц измерения, такие как длина, площадь, объем, угол и другие поддерживаемые типы в зависимости от версии Dynamo.

В приведенном ниже примере узел `Units` создает список объектов единиц Dynamo. Затем эти единицы измерения можно выбрать, отфильтровать и передать в узлы, для которых требуется входное значение `DynamoUnits.Unit`.
