## Подробности
Узел `Select Phase` позволяет выбрать определенную стадию из доступных в активном проекте Revit и возвращает нужную.

В приведенном ниже примере тип семейства и точка используются для размещения экземпляра семейства. Параметр экземпляра `Phase Created` изменяется с использованием узла `Select Phase` и входных данных категории Existing.
