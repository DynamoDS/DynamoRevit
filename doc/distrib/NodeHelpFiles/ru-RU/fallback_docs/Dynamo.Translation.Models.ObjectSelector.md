## Подробности
Узел `Select Geometry File Objects` позволяет вручную выбирать объекты, которые будут обрабатываться графом, чтобы импортировать только нужный объем геометрии.

В приведенном ниже примере геометрия САПР импортируется и используется узлом `Select Geometry File Objects`. Требуемые объекты для вывода выбираются вручную, например объекты с идентификаторами 16, 27 и 33, как показано здесь.
