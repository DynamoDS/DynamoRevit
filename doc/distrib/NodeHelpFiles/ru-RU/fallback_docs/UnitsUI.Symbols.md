## Подробности
Узел `Symbols` содержит список доступных для выбора обозначений единиц измерения, которые можно использовать в Dynamo при форматировании или синтаксическом анализе значений с единицами измерения.

В приведенном ниже примере узел `Symbols` используется для выбора обозначения единицы измерения из доступной библиотеки обозначений единиц измерения Dynamo. На выходе получается объект `DynamoUnits.Symbol`, который можно использовать в качестве входных данных при форматировании дробных значений.
