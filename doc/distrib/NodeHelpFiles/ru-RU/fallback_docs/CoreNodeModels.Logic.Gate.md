## Подробности
Узел `Gate` управляет передачей входных данных в соответствии с логическим значением. Если узел открыт (т. е. ему присвоено значение True), входные данные передаются на выход. Если закрыт (т. е. ему присвоено значение False), то передача данных блокируется.

В приведенном ниже примере узел `Gate` используется для предотвращения разнесения геометрии при каждом запуске графа. Если узел открыт (True), новая геометрия проходит через него и разносится. Если же он закрыт (False), то геометрия блокируется, не передается дальше и не разносится снова.
