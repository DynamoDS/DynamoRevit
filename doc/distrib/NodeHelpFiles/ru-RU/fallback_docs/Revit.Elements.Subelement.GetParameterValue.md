## Подробности
Узел `Subelement.GetParameterValue` извлекает значение параметра из подэлемента Revit.

В приведенном ниже примере выбираются все элементы на текущем виде и фильтруются для отображения только элементов, содержащих подэлементы. Затем подэлементы вместе с идентификаторами параметров используются в качестве входных данных для узла `Subelement.GetParameterValue`. На выходе получается значение параметра из заданного подэлемента.
