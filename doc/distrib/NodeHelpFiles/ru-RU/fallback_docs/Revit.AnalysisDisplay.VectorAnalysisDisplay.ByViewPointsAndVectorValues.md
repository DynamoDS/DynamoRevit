## Подробности
Узел `VectorAnalysisDisplay.ByViewPointsAndVectorValues` отображает результаты векторного анализа на виде Revit. Входной вид определяет, где будет отображаться представление анализа. Точки определяют местоположение маркеров анализа, векторы — направление отображаемого анализа, а значения — числовой результат, связанный с каждой точкой. На выходе в выбранном виде отображаются результаты анализа в Revit.

В приведенном ниже примере создаются две точки для определения местоположения образцов на 3D-виде в Revit. Затем создаются два вектора для определения данных направленного анализа в этих местоположениях. Точки и векторы объединяются в списки и используются в качестве входных данных для узла `VectorAnalysisDisplay.ByViewPointsAndVectorValues` вместе с видом, именем и описанием анализа. На выходе получается представление результатов векторного анализа на выбранном виде Revit.
