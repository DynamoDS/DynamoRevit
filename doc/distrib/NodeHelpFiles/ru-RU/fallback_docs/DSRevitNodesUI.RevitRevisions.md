## Подробности
Узел `Select Revision` позволяет выбрать нужное изменение из доступных в текущем проекте Revit.

В приведенном ниже примере узел `Select Revision` используется для выбора варианта Seq. 1 - Schematic Design. Выходные данные затем используются в качестве входных при получении даты изменения и статуса публикации.

Дополнительные сведения об изменениях см. в [документации по Revit](https://help.autodesk.com/view/RVT/2025/RUS/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4).
