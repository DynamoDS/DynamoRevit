## Подробности
Узел `Import Geometry File` позволяет импортировать внешние данные геометрии или модели в приложение Dynamo для просмотра, фильтрации или использования в последующих рабочих процессах. Он выступает в качестве основной отправной точки для добавления поддерживаемого импортированного содержимого в граф и дает возможность приложению Dynamo интерпретировать входящий файл или объект и предоставлять его для дальнейшей обработки.

В приведенном ниже примере выбран файл North Arrows.dwg, который используется в качестве входных данных для узла `Import Geometry File`. Выходные данные содержат всю геометрию и связанные с ней данные, содержащиеся в импортированном файле.
