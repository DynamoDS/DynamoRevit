## Подробности
Узел `Subelement.Element` возвращает родительский элемент Revit, к которому принадлежит данный подэлемент.

В приведенном ниже примере выбираются все элементы на текущем виде и фильтруются для отображения только элементов, содержащих подэлементы. Затем подэлементы используются в качестве входных данных для узла `Subelement.Element`. На выходе получается список родительских элементов, связанных с каждым подэлементом.
