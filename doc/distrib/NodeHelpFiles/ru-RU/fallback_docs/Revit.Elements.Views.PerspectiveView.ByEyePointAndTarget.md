## Подробности
Узел `PerspectiveView.ByEyePointAndTarget` создает 3D-вид Revit в перспективе с помощью точки обзора, целевой точки, имени и логического значения `isolateElement`.

В приведенном ниже примере в Dynamo создаются две точки, которые используются в качестве точки обзора для камеры и целевой точки. Они используются в качестве входных данных для узла `PerspectiveView.ByEyePointAndTarget` вместе с именем и логическим значением. На выходе получается новый вид Revit в перспективе, направленный от точки обзора к целевой точке.
