## Подробности
Узел `Mesh.BoundingBox` возвращает ограничивающую рамку заданной сети.

В приведенном ниже примере генерируются точки, на основе которых создается сеть, используемая затем в качестве входных данных для узла `Mesh.BoundingBox`. На выходе получается ограничивающая рамка, необходимая для извлечения `MinPoint`.
