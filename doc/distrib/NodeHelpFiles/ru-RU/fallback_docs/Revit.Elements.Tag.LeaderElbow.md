## Подробности
Узел `Tag.LeaderElbow` возвращает точку сгиба линии выноски для марки. Входным значением является элемент марки Revit, а выходным — точка Dynamo, обозначающая местоположение изгиба выноски.

В приведенном ниже примере из активного вида Revit выбирается марка, которая используется в качестве входных данных для узла `Tag.LeaderElbow`. Результатом является местоположение точки, в которой изгибается каждая выноска марки.
