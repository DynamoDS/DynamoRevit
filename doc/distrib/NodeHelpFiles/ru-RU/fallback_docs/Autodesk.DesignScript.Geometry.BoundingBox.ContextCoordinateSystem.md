## Подробности
Узел `BoundingBox.ContextCoordinateSystem` возвращает систему координат, которая определяет ориентацию ограничивающей рамки. Благодаря этому программа Dynamo может отображать повернутые или локально ориентированные ограничивающие рамки.

В приведенном ниже примере выбирается дверь и ее геометрия используется для создания ограничивающей рамки. Затем она используется как входные данные для узла `BoundingBox.ContextCoordinateSystem`, где отображается система координат.
