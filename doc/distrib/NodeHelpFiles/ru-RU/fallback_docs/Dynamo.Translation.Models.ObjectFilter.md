## Подробности
Узел `Filter Geometry File Objects` предоставляет правила фильтрации для объектов, обрабатываемых в разных системах.

В приведенном ниже примере файл North Arrows.dwg импортируется в Dynamo, а узел `Filter Geometry File Objects` используется для настройки поиска, чтобы были показаны только объекты с идентификатором слоя 13. В последнем узле отображаются все объекты с этими свойствами.
