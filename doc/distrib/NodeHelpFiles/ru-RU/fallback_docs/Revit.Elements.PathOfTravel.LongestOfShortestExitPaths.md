## Подробности
Узел `PathOfTravel.LongestOfShortestExitPaths` создает траекторию движения, представляющую собой самый длинный маршрут среди коротких маршрутов от группы точек до одной или нескольких точек выхода. Каждая начальная точка сравнивается с доступными выходами, и Revit определяет ближайшую допустимую траекторию выхода для каждой точки. Затем узел возвращает путь с самой длинной дистанцией перемещения среди самых коротких результатов.

В приведенном ниже примере сначала создаются уровень и вид в плане этажа, чтобы получить вид Revit, необходимый для расчета траектории движения. Несколько точек создаются с помощью узла `Point.ByCoordinates` и объединяются в список, содержащий возможные места выхода. Узел `PathOfTravel.LongestOfShortestExitPaths` использует вид в плане этажа и список точек назначения для расчета траекторий перемещения, возвращая траекторию с наибольшим расстоянием перемещения.
