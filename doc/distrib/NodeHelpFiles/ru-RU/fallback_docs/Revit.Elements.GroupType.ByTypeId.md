## Подробности
Узел `GroupType.ByTypeId` в основном используется в рабочих процессах создания параметров и управления ими, в которых группа параметров Revit должна быть задана программным способом. Входные данные — это строка, которая представляет собой идентификатор типа группы параметров Revit. На выходе получается объект `GroupType`, который затем можно использовать в узлах, требующих классификации группировки параметров.

В приведенном ниже примере создается несколько строк, представляющих собой идентификаторы типов групп параметров Revit, которые объединяются в список. Затем этот список используется в качестве входных данных для узла `GroupType.ByTypeId`. В результате создается список объектов `GroupType` программы Revit, которые представляют соответствующие группы параметров.
