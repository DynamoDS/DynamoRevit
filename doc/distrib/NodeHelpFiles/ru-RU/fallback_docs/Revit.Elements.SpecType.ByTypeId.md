## Подробности
Узел `SpecType.ByTypeId` преобразует строку Spec TypeId программы Revit в объект `SpecType`. Типы мини-каталогов определяют тип данных для параметра в Revit, например длину, площадь, угол, материал, силу, текст, целое число и многие другие. Эта функция обычно используется при создании общих параметров, параметров проекта или определений параметров в новых версиях Revit, в которых компания Autodesk заменила старую систему `ParameterType` на объекты Forge TypeId.

В приведенном ниже примере строка, представляющая объект Spec TypeId программы Revit, передается в узел `SpecType.ByTypeId`. На выходе получается объект `SpecType`, который затем можно использовать при создании определения параметра, чтобы программа Revit понимала, какой тип данных должен храниться в параметре.
