## Подробности
Узел `AxonometricView.ByEyePointTargetAndBoundingBox` создает аксонометрический 3D-вид в Revit с использованием точки обзора, целевой точки, ограничивающей рамки, имени и логического значения `isolateElement`.

В приведенном ниже примере создаются точки, определяющие точку обзора и целевое положение для 3D-вида. Для управления границами обрезки вида также создается ограничивающая рамка. Эти входные данные используются для узла `AxonometricView.ByEyePointTargetAndBoundingBox` вместе с именем и логическим значением. На выходе получается новый аксонометрический 3D-вид в Revit.
