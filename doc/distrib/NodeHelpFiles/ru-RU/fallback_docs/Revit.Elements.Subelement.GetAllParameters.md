## Подробности
Узел `Subelement.GetAllParameters` извлекает внутренние идентификаторы параметров подэлементов Revit, а не отображаемые имена параметров.

В приведенном ниже примере выбираются все элементы на текущем виде и фильтруются для отображения только элементов, содержащих подэлементы. Затем подэлементы используются в качестве входных данных для узла `Subelement.GetAllParameters`. На выходе получается список идентификаторов параметров, связанных с каждым подэлементом. Последний узел показывает, какой выходной порт используется для получения значений параметров.
