## Подробности
Этот узел извлекает значение ScheduleFieldId, связанное с заданным объектом ScheduleFilter. Каждый фильтр спецификации в Revit связан с определенным полем (например, «Уровень», «Семейство и типоразмер», «Площадь»). Этот узел предоставляет данные об этом соединении, возвращая идентификатор поля, используемый для фильтра.

В этом примере создается фильтр спецификации, который используется в качестве входных данных для узла ScheduleFilter.FieldId.
