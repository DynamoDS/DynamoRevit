## Подробности
Узел `PolyCurve.OffsetMany` смещает объект PolyCurve, формируя один или несколько новых объектов PolyCurve на заданном расстоянии смещения в указанной плоскости.

В приведенном ниже примере узел `PolyCurve.ByPoints` создает входную геометрию для узла `PolyCurve.OffsetMany`. Значение расстояния со знаком «+» или «–» определяет направление смещения, логическое значение `extendCircular` определяет способ обработки дуговых ребер, а вектор `planeNormal` указывает направление нормали плоскости, в которой создается смещение.
