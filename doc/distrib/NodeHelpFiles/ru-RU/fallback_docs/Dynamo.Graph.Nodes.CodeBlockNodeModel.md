## Подробности
Узел `Code Block` — это компактный текстовый формат для записи кода DesignScript непосредственно в Dynamo с целью создания значений, выполнения вычислений, определения переменных и построения логики. Узел `Code Block` может содержать отдельные значения, списки, диапазоны, математические выражения, строковые значения, вызовы функций и назначения переменных.

В приведенном ниже примере показано, как с помощью `Code Block` создается математическое выражение. Дополнительные сведения см. в [руководстве по DesignScript](https://dynamobim.org/wp-content/links/DesignScriptGuide.pdf).
