## Подробности
Узел `Remember` сохраняет значение в файле Dynamo, чтобы его можно было впоследствии вызвать для графа, даже если входные данные имеют нулевое значение. Это позволяет сохранять данные между выполнениями графа, поддерживать состояние или создавать ссылки на ранее сохраненную информацию, не создавая ее каждый раз заново.

В приведенном ниже примере выбирается один этаж и извлекается геометрия, которая используется в качестве входных данных для узла `Remember`. Сохраненный результат можно после этого повторно использовать в качестве выходных данных для графа.
