## Подробности
Узел `Dimension.ByReferences` размещает размер вдоль входной линии на выбранном виде, используя заданные ссылки. На выходе предоставляется элемент Dimension программы Revit.

В приведенном ниже примере создается несколько точек, которые соединяются с узлами Line для создания кривых модели в Revit. Затем кривые модели преобразуются в ссылки на кривые Revit. Ссылки объединяются в список и используются в качестве входных данных категории `references` для узла `Dimension.ByReferences`. Создаются дополнительные линии, определяющие положение и направление размеров. Активный вид Revit также предоставляется как входное значение категории `view`.
