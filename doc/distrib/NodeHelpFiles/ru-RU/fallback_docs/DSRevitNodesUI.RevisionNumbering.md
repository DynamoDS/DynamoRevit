## Подробности
Узел `Select Revision Numbering` указывает на метод нумерации изменений в проекте. Доступные варианты: PerProject и PerSheet, соответствующие параметрам `PerProject` и `PerSheet`.

В приведенном ниже примере создается изменение, а в качестве одного из входных параметров используется узел `Select Revision Numbering`.

Дополнительные сведения об изменениях см. в [документации по Revit](https://help.autodesk.com/view/RVT/2025/RUS/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4).
