## Подробности
Узел `Leader End Condition` предоставляет выбираемое значение условия из Revit для конца выноски. Доступные варианты: Free или Attached.

В приведенном ниже примере маркированы все стены на виде L1. Эти марки используются со значением Free, указанном в узле `Leader End Condition`, как входные данные, которые позволяют указывать значения условий для конца выноски.
