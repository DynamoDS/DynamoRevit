## Подробности
Узел Materials позволяет выбрать один элемент материала из алфавитного списка всех элементов материала в текущем документе (файле).

Выбранный материал можно использовать в качестве входных данных для узлов, например Element.SetParameterByName, при назначении материала параметру материала элемента, а также при работе с узлами Material для запроса их свойств.
