## Im Detail
`Select Revision` stellt eine Möglichkeit zum Auswählen einer Revision aus dem aktuellen Revit-Projekt bereit.

Im folgenden Beispiel wird `Select Revision` mit ausgewählter Option "Seq. 1 - Schematischer Entwurf" verwendet. Die Ausgabe wird dann als Eingabe zum Abrufen des Datums und Ausgabestatus der Revision verwendet.

Weitere Informationen zu Revisionen finden Sie unter [Revit-Dokumentation](https://help.autodesk.com/view/RVT/2025/DEU/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4).
