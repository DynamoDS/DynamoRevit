## Im Detail
`PerspectiveView.ByEyePointTargetAndElement` erstellt eine neue perspektivische Revit-3D-Ansicht mit einer Augenposition, einem Zielpunkt, einem Element, einem Namen und einem booleschen Wert für `isolateElement`.

Im folgenden Beispiel wird ein Revit-Element ausgewählt und als Fokus der perspektivischen Ansicht verwendet. Es werden ein Punkt für die Kameraposition und ein weiterer Punkt für die Zielposition erstellt. Diese werden zusammen mit dem ausgewählten Element als Eingaben für `PerspectiveView.ByEyePointTargetAndElement` verwendet. Die Ausgabe ist eine neue perspektivische Ansicht, bei der die Betrachtung von der Augenposition zum Zielpunkt erfolgt und die Ansichtsgrenzen auf dem ausgewählten Element basieren.
