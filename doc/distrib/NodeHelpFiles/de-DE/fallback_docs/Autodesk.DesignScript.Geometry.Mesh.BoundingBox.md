## Im Detail
`Mesh.BoundingBox` gibt den Begrenzungsrahmen eines bestimmten Netzes zurück.

Im folgenden Beispiel werden Punkte generiert und zum Erstellen eines Netzes verwendet, das dann als Eingabe für `Mesh.BoundingBox` verwendet wird. Die Ausgabe ist ein Begrenzungsrahmen, der zum Extrahieren von `MinPoint` verwendet wird.
