## Im Detail
`Select Revision Number Type` stellt einen Revisionsnummerierungstyp zur Verwendung in revisionsbezogenen Arbeitsabläufen bereit. Zur Auswahl stehen Numerisch, Alphanumerisch oder Kein.

In folgenden Beispiel wird eine Revision erstellt, und `Select Revision Number Type` wird als eine der Eingaben verwendet.

Weitere Informationen zu Revisionen finden Sie unter [Revit-Dokumentation](https://help.autodesk.com/view/RVT/2025/DEU/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4).
