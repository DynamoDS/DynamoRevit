## Im Detail
`Spacing Rule Layout` ruft das Abstandsregel-Layout aus einem geteilten Pfadelement ab. Der geteilte Pfad wird als Eingabe verwendet, und die Ausgabe entspricht der aktuellen Abstands-Layoutregel, die steuert, wie Punkte entlang des Pfads verteilt werden.

Im folgenden Beispiel wird eine geteilte Oberfläche aus dem Revit-Modell ausgewählt und als Eingabe zum Ändern der zugehörigen Parameter verwendet. Ein Zeichenfolgenblock stellt den Parameternamen "Layout" bereit, während `Spacing Rule Layout` den Wert für den Abstandsregeltyp angibt. Das Diagramm aktualisiert die Layoutregel für die geteilte Oberfläche in `FixedNumber`. Die Ausgabe ist das geänderte Element der geteilten Oberfläche.
