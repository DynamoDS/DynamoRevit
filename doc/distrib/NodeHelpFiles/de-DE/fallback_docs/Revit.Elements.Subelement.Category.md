## Im Detail
`Subelement.Category` ruft die einem Revit-Teilelement zugewiesene Kategorie ab. Teilelemente sind Komponenten oder Teile von größeren Revit-Elementen, z. B. Layer, Pfosten, Fassadenelemente, Bewehrungen oder verschachtelte Geometrie, die in einem übergeordneten Element enthalten sein können.

Im folgenden Beispiel werden alle Elemente in der aktuellen Ansicht ausgewählt und gefiltert, sodass nur die Elemente angezeigt werden, die Teilelemente enthalten. Die Teilelemente werden dann als Eingabe für `Subelement.Category` verwendet. Die Ausgabe ist eine Liste von Kategorien, die mit den einzelnen Teilelementen verknüpft sind.
