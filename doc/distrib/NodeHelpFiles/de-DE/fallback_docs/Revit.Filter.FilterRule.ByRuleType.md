## Im Detail
`FilterRule.ByRuleType` erstellt eine Revit-Filterregel basierend auf einem ausgewählten Regeltyp, Parameter und Vergleichswert.

Im folgenden Beispiel wird ein Wandtyp identifiziert und der Parameter `Fire Rating` zusammen mit einem Wert und einem Regeltyp als Eingabe für `FilterRule.ByRuleType` verwendet. Die Ausgabe ist eine Filterregel, die anschließend auf eine Ansicht angewendet wird.
