## Im Detail
Mit `Select Geometry File Objects` wird der Bereich der importierten Geometrie eingeschränkt, indem die manuelle Auswahl der Objekte ermöglicht wird, die an das Diagramm übergeben werden.

Im folgenden Beispiel wird CAD-Geometrie importiert und in `Select Geometry File Objects` verwendet. Bestimmte Objekte werden manuell für die Ausgabe ausgewählt, wie die hier gezeigten Objekte mit den IDs 16, 27 und 33.
