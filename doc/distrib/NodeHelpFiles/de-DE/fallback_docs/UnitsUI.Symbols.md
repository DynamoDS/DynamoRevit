## Im Detail
`Symbols` stellt eine auswählbare Liste mit Einheitensymbolen bereit, die Dynamo beim Formatieren oder Analysieren von einheitenbasierten Werten verwenden kann.

Im folgenden Beispiel wird `Symbols` verwendet, um ein Einheitensymbol aus der Dynamo-Bibliothek für verfügbare Einheitensymbole auszuwählen. Die Ausgabe ist ein `DynamoUnits.Symbol`-Objekt, das als Eingabe beim Formatieren von Bruchwerten verwendet werden kann.
