## Im Detail
`Subelement.GetParameterValue` ruft den Wert eines Parameters aus einem Revit-Teilelement ab.

Im folgenden Beispiel werden alle Elemente in der aktuellen Ansicht ausgewählt und gefiltert, sodass nur die Elemente angezeigt werden, die Teilelemente enthalten. Die Teilelemente werden dann zusammen mit den Parameter-IDs als Eingabe für `Subelement.GetParameterValue` verwendet. Die Ausgabe ist der Parameterwert aus dem angegebenen Teilelement.
