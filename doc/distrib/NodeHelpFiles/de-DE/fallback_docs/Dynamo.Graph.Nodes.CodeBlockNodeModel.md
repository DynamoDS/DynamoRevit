## Im Detail
`Code Block` stellt ein kompaktes, textbasiertes Format zum Schreiben von DesignScript-Code direkt in Dynamo bereit, um Werte zu erstellen, Berechnungen durchzuführen, Variablen zu definieren und Logik zu erstellen. `Code Block` kann einzelne Werte, Listen, Bereiche, mathematische Ausdrücke, Zeichenfolgenwerte, Funktionsaufrufe und Variablenzuweisungen enthalten.

Im folgenden Beispiel demonstriert `Code Block` einen mathematischen Ausdruck. Weitere Informationen finden Sie unter [DesignScript-Handbuch](https://dynamobim.org/wp-content/links/DesignScriptGuide.pdf).
