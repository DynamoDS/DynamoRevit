## Im Detail
`PerspectiveView.ByEyePointAndTarget` erstellt eine neue perspektivische Revit-3D-Ansicht mit einer Augenposition, einem Zielpunkt, einem Namen und einem booleschen Wert für `isolateElement`.

Im folgenden Beispiel werden zwei Punkte in Dynamo erstellt und als Kameraaugenposition und Zielpunkt verwendet. Diese werden zusammen mit einem Namen und einem booleschen Wert als Eingaben für `PerspectiveView.ByEyePointAndTarget` verwendet. Die Ausgabe ist eine neue perspektivische Revit-Ansicht, bei der die Betrachtung von der Augenposition zum Zielpunkt erfolgt.
