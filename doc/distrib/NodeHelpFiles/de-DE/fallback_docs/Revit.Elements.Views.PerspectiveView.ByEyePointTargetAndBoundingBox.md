## Im Detail
`PerspectiveView.ByEyePointTargetAndBoundingBox` erstellt eine neue perspektivische Revit-3D-Ansicht mit einer Augenposition, einem Zielpunkt, einem Begrenzungsrahmen, einem Namen und einem booleschen Wert für `isolateElement`.

Im folgenden Beispiel werden Punkte erstellt, um die Augen- und Zielposition für die 3D-Ansicht zu definieren. Außerdem wird ein Begrenzungsrahmen erstellt, um die Zuschneidegrenzen der Ansicht zu steuern. Diese Eingaben werden zusammen mit `PerspectiveView.ByEyePointTargetAndBoundingBox` sowie einem Namen und einem booleschen Wert verwendet. Die Ausgabe ist eine neue perspektivische 3D-Ansicht in Revit.
