## Im Detail
`Select Revision Visibility` stellt einen Sichtbarkeitsmodus für Revit-Revisionen bereit. Die Optionen lauten `CloudAndTagVisible`, `TagVisible` und `Hidden`.

Im folgenden Beispiel wird eine Revision mit `Select Revision Visibility` als eine der Eingaben erstellt.

Weitere Informationen zu Revisionen finden Sie unter [Revit-Dokumentation](https://help.autodesk.com/view/RVT/2025/DEU/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4).
