## Im Detail
`Subelement.Element` gibt das übergeordnete Revit-Element zurück, zu dem ein bestimmtes Teilelement gehört.

Im folgenden Beispiel werden alle Elemente in der aktuellen Ansicht ausgewählt und gefiltert, sodass nur die Elemente angezeigt werden, die Teilelemente enthalten. Die Teilelemente werden dann als Eingabe für `Subelement.Element` verwendet. Die Ausgabe ist eine Liste der übergeordneten Elemente, die mit den einzelnen Teilelementen verknüpft sind.
