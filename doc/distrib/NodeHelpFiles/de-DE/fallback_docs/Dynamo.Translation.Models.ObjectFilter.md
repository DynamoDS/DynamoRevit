## Im Detail
`Filter Geometry File Objects` stellt Filterregeln für Objekte, die zwischen Systemen verarbeitet werden, bereit.

Im folgenden Beispiel wird die Datei North Arrows.dwg in Dynamo importiert, und `Filter Geometry File Objects` wird verwendet, um die Suche so anzupassen, dass nur Objekte mit LayerID = 13 angezeigt werden. Im letzten Block werden alle Objekte mit diesen Eigenschaften angezeigt.
