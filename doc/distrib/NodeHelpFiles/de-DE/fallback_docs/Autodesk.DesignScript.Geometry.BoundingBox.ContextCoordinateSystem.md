## Im Detail
`BoundingBox.ContextCoordinateSystem` gibt das Koordinatensystem zurück, das die Ausrichtung des Begrenzungsrahmens definiert, sodass Dynamo gedrehte oder lokal ausgerichtete Begrenzungsrahmen darstellen kann.

Im folgenden Beispiel wird eine Tür ausgewählt, und deren Geometrie wird verwendet, um einen Begrenzungsrahmen zu erstellen. Dies wird dann als Eingabe für `BoundingBox.ContextCoordinateSystem` verwendet, wo das Koordinatensystem bereitgestellt wird.
