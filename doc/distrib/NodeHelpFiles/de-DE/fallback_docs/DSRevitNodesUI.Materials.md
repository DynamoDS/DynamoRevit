## Im Detail
Mit `Materials` können Sie ein einzelnes Materialelement aus einer alphabetischen Liste aller Materialelemente im aktuellen Dokument (Datei) auswählen.

Das ausgewählte Material kann als Eingabe für Blöcke wie `Element.SetParameterByName` verwendet werden, um ein Material einem Materialparameter eines Elements zuzuweisen, oder für `Material`-Blöcke, um deren Eigenschaften abzufragen.
