## Im Detail
`Units` stellt eine Liste mit verfügbaren Einheitentypen bereit, die verwendet werden können, wenn ein anderer Block eine `DynamoUnits.Unit`-Eingabe erfordert. Die Ausgabe enthält je nach der Dynamo-Version Einheitentypen wie Länge, Fläche, Volumen, Winkel und andere unterstützte Typen.

Im folgenden Beispiel generiert `Units` eine Liste mit Dynamo-Einheitenobjekten. Diese Einheiten können dann ausgewählt oder gefiltert und an Blöcke übergeben werden, die eine `DynamoUnits.Unit`-Eingabe erfordern.
