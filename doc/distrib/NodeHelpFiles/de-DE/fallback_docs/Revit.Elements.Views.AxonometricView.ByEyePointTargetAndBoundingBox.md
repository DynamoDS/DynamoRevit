## Im Detail
`AxonometricView.ByEyePointTargetAndBoundingBox` erstellt in Revit eine neue axonometrische 3D-Ansicht mit einer Augenposition, einem Zielpunkt, einem Begrenzungsrahmen, einem Namen und einem booleschen Wert für `isolateElement`.

Im folgenden Beispiel werden Punkte erstellt, um die Augenposition und die Zielposition für die 3D-Ansicht zu definieren. Außerdem wird ein Begrenzungsrahmen erstellt, um die Zuschneidegrenzen der Ansicht zu steuern. Diese Eingaben werden zusammen mit `AxonometricView.ByEyePointTargetAndBoundingBox` sowie einem Namen und einem booleschen Wert verwendet. Die Ausgabe ist eine neue axonometrische 3D-Ansicht in Revit.
