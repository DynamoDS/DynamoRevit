## Im Detail
`Select Revision Numbering` stellt die Revisionsnummerierungsmethode bereit, die im Projekt verwendet wird. Revisionen können entsprechend der Option `PerProject` und `PerSheet` entweder nach Projekt oder nach Plan nummeriert werden.

Im folgenden Beispiel wird eine Revision erstellt, und `Select Revision Numbering` wird als eine der Eingaben verwendet.

Weitere Informationen zu Revisionen finden Sie unter [Revit-Dokumentation](https://help.autodesk.com/view/RVT/2025/DEU/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4).
