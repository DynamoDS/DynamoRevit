## Im Detail
Mit `Import Geometry File` werden externe Geometrie- oder Modelldaten in Dynamo importiert, sodass diese angezeigt, gefiltert oder in nachgelagerten Arbeitsabläufen verwendet werden können. Dies fungiert als Haupteinstiegspunkt für die Integration unterstützter importierter Inhalte in das Diagramm, sodass Dynamo die eingehende Datei oder das Objekt interpretieren und für die weitere Verarbeitung verfügbar machen kann.

Im folgenden Beispiel wird die Datei Nord Arrows.dwg ausgewählt und als Eingabe für `Import Geometry File` verwendet. Die Ausgabe bietet Zugriff auf die gesamte Geometrie und die zugehörigen Daten in der importierten Datei.
