## 상세
`Import Geometry File`은 외부 형상 또는 모델 데이터를 Dynamo로 가져와 확인하거나 필터링하거나 후속 워크플로에서 사용할 수 있도록 합니다. 이 노드는 지원되는 가져오기 컨텐츠를 그래프로 가져오는 진입점 역할을 하며, Dynamo가 가져오는 파일이나 객체를 해석하여 후속 처리에 사용할 수 있도록 제공합니다.

아래 예제에서는 North Arrows.dwg 파일을 선택하여 `Import Geometry File`의 입력으로 사용합니다. 출력은 가져온 파일에 포함된 모든 형상과 관련 데이터에 대한 액세스를 제공합니다.
