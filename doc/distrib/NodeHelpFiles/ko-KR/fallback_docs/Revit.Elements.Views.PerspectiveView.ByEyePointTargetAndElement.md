## 상세
`PerspectiveView.ByEyePointTargetAndElement`는 시점, 대상 점, 요소, 이름 및 `isolateElement` 부울 값을 사용하여 새로운 Revit 원근 3D 뷰를 작성합니다.

아래 예제에서는 Revit 요소를 선택하여 원근 뷰의 초점 대상으로 사용합니다. 카메라 위치를 정의하는 점과 대상 위치를 정의하는 점을 각각 작성합니다. 이러한 점과 선택한 요소를 `PerspectiveView.ByEyePointTargetAndElement`의 입력으로 사용합니다. 출력은 시점에서 대상 점을 향해 바라보는 새로운 원근 뷰이며, 뷰 범위는 선택한 요소를 기준으로 설정됩니다.
