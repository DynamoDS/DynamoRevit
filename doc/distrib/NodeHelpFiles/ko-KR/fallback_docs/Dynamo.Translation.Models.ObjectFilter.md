## 상세
`Filter Geometry File Objects`는 시스템 간에 처리되는 객체에 적용할 필터링 규칙을 제공합니다.

아래 예제에서는 North Arrows.dwg 파일을 Dynamo로 가져온 후 `Filter Geometry File Objects`를 사용하여 LayerID = 13인 객체만 표시하도록 검색을 사용자 지정합니다. 마지막 노드는 이러한 특성을 만족하는 모든 객체를 표시합니다.
