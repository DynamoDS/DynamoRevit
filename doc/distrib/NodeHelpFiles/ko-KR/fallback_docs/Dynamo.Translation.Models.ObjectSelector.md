## 상세
`Select Geometry File Objects`는 가져온 형상의 범위를 좁혀 그래프를 통해 전달할 객체를 수동으로 선택할 수 있도록 합니다.

아래 예제에서는 CAD 형상을 가져와 `Select Geometry File Objects`의 입력으로 사용합니다. 그런 다음 ID가 16, 27, 33인 객체와 같이 특정 객체를 수동으로 선택하여 출력합니다.
