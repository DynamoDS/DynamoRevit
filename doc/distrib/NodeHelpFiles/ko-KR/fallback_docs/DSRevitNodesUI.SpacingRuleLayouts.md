## 상세
`Spacing Rule Layout`은 분할 경로 요소의 간격 규칙 레이아웃을 가져옵니다. 분할 경로를 입력으로 사용하며, 출력은 경로를 따라 점이 배치되는 방식을 제어하는 현재 간격 레이아웃 규칙입니다.

아래 예제에서는 Revit 모델에서 분할 표면을 선택하여 해당 매개변수를 수정하는 입력으로 사용합니다. 문자열 노드는 "Layout" 매개변수 이름을 제공하고, `Spacing Rule Layout`은 간격 규칙 유형 값을 제공합니다. 이 그래프는 분할된 표면의 레이아웃 규칙을 `FixedNumber`로 변경합니다. 출력은 수정된 분할 표면 요소입니다.
