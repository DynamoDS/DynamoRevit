## 상세
`PolyCurve.OffsetMany`는 입력된 간격띄우기 거리와 평면을 기준으로 하나 이상의 새 PolyCurve를 간격띄우기합니다.

아래 예제에서는 `PolyCurve.ByPoints` 노드가 `PolyCurve.OffsetMany`의 입력 형상을 작성합니다. 부호 있는 거리 값(+ 또는 -)은 간격띄우기 방향을 제어하고, `extendCircular` 부울 값은 원형 모서리를 처리하는 방식을 결정하며, `planeNormal` 벡터는 간격띄우기가 작성되는 평면의 법선 방향을 정의합니다.
