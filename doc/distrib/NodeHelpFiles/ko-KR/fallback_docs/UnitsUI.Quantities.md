## 상세
`Quantities`는 선택 가능한 수량 유형(예: 길이, 면적 또는 체적)을 제공하고, 해당 수량 유형과 연결된 단위 정의를 추출합니다. 이러한 수량은 실제 단위 값이 아니라 측정 대상의 유형을 나타냅니다. 예를 들어 길이는 수량 유형이고, 피트 또는 미터는 해당 수량 유형에 속하는 단위입니다.

아래 예제에서는 `Quantities`를 사용하여 길이, 면적 또는 체적과 같은 값을 선택하고, 이에 연결된 단위 정의를 추출합니다.
