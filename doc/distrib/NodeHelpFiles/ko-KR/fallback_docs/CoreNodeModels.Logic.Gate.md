## 상세
`Gate`는 부울 값을 기준으로 입력 데이터의 통과 여부를 제어합니다. 게이트가 열려 있으면(True) 입력 데이터가 출력으로 전달됩니다. 게이트가 닫혀 있으면(False) 입력 데이터는 차단됩니다.

아래 예제에서는 `Gate`를 사용하여 그래프를 실행할 때마다 형상이 분해되지 않도록 합니다. 게이트가 열려 있으면(True) 새로 작성된 형상이 통과되어 분해됩니다. 게이트가 닫혀 있으면(False) 형상이 차단되어 전달되지 않거나 다시 분해되지 않습니다.
