## 상세
`Subelement.Category`는 Revit 하위 요소에 할당된 카테고리를 가져옵니다. 하위 요소는 상위 요소 내에 존재하는 구성요소 또는 부분으로, 레이어, 멀리언, 커튼 패널, 보강 철근 또는 중첩된 형상 등이 이에 해당합니다.

아래 예제에서는 현재 뷰의 모든 요소를 선택한 후 하위 요소를 포함하는 요소만 표시하도록 필터링합니다. 그런 다음 하위 요소를 `Subelement.Category`의 입력으로 사용합니다. 출력은 각 하위 요소와 연결된 카테고리 리스트입니다.
