## 상세
`Select Revision`은 현재 Revit 프로젝트에서 수정기호를 선택하는 방법을 제공합니다.

아래 예제에서는 `Select Revision`에서 "Seq. 1 - Schematic Design"을 선택합니다. 그런 다음 출력을 입력으로 사용하여 해당 수정기호의 날짜와 발행 상태를 가져옵니다.

수정기호에 대한 자세한 내용은 [Revit 문서](https://help.autodesk.com/view/RVT/2025/KOR/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4)를 참조하십시오.
