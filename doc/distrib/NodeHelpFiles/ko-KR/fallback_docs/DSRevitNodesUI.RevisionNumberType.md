## 상세
`Select Revision Number Type`은 수정기호 관련 워크플로에서 사용할 수정기호 번호 지정 유형을 제공합니다. 선택 가능한 옵션은 숫자, 영숫자 또는 없음입니다.

아래 예제에서는 수정기호를 생성한 후 `Select Revision Number Type`을 입력 중 하나로 사용합니다.

수정기호에 대한 자세한 내용은 [Revit 문서](https://help.autodesk.com/view/RVT/2025/KOR/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4)를 참조하십시오.
