## 상세
`Subelement.GetParameterValue`는 Revit 하위 요소에서 매개변수 값을 가져옵니다.

아래 예제에서는 현재 뷰의 모든 요소를 선택한 후 하위 요소를 포함하는 요소만 표시하도록 필터링합니다. 그런 다음 하위 요소와 매개변수 ID를 함께 `Subelement.GetParameterValue`의 입력으로 사용합니다. 출력은 지정된 하위 요소의 매개변수 값입니다.
