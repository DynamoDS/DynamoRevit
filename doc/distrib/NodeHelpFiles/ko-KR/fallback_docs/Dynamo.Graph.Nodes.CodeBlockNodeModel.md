## 상세
`Code Block`은 DesignScript 코드를 Dynamo에서 직접 작성할 수 있는 간결한 텍스트 기반 형식을 제공합니다. 이를 사용하여 값을 작성하고, 계산을 수행하며, 변수를 정의하고, 논리를 구성할 수 있습니다. `Code Block`에는 단일 값, 리스트, 범위, 수학식, 문자열 값, 함수 호출 및 변수 할당을 포함할 수 있습니다.

아래 예제에서는 `Code Block`을 사용하여 수학식을 작성하는 방법을 보여 줍니다. 자세한 내용은 [DesignScript 가이드](https://dynamobim.org/wp-content/links/DesignScriptGuide.pdf)를 참조하십시오.
