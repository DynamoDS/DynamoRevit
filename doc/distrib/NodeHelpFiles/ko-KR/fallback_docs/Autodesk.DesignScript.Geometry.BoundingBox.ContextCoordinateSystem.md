## 상세
`BoundingBox.ContextCoordinateSystem`은 경계 상자의 방향을 정의하는 좌표계를 반환합니다. 이를 통해 Dynamo에서 회전된 경계 상자 또는 로컬 방향으로 정렬된 경계 상자를 표현할 수 있습니다.

아래 예제에서는 문을 선택한 후 해당 형상을 사용하여 경계 상자를 생성합니다. 그런 다음 이 경계 상자를 `BoundingBox.ContextCoordinateSystem`의 입력으로 사용하여 해당 좌표계를 표시합니다.
