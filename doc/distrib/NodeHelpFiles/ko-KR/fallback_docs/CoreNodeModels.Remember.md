## 상세
`Remember`는 값을 Dynamo 파일에 저장하여 나중에 그래프에서 다시 사용할 수 있도록 합니다. 입력이 null인 경우에도 저장된 값을 불러올 수 있습니다. 이 기능은 실행 간 데이터를 유지하거나 상태를 보존하거나, 매번 다시 작성하지 않고 이전에 저장한 정보를 참조할 때 유용합니다.

아래 예제에서는 단일 바닥을 선택한 후 형상을 추출하여 `Remember`의 입력으로 사용합니다. 저장된 결과는 그래프에서 다시 사용할 수 있도록 출력으로 제공됩니다.
