## Informacje szczegółowe
Węzeł Select Revision umożliwia wybranie określonej rewizji z aktywnego projektu programu Revit.

W tym przykładzie węzeł Select Revision jest używany przez wybranie opcji „Seq. 1 - Schematic Design”. Jego dane wyjściowe służą następnie jako wejście w celu pobrania daty i stanu wydania rewizji.

Aby uzyskać więcej informacji na temat rewizji, zapoznaj się z [dokumentacją programu Revit](https://help.autodesk.com/view/RVT/2025/ENU/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4)
