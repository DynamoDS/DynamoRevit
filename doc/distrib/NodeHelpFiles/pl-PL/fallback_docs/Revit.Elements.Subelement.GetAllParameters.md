## Informacje szczegółowe
Węzeł Subelement.GetAllParameters pobiera wewnętrzne identyfikatory parametrów programu Revit elementów podrzędnych, a nie nazwy wyświetlane parametrów.

W poniższym przykładzie wszystkie elementy w bieżącym widoku zostają wybrane i przefiltrowane, aby wyświetlić tylko te elementy, które zawierają elementy podrzędne. Elementy podrzędne są następnie używane jako dane wejściowe węzła Subelement.GetAllParameters. Wynikiem jest lista identyfikatorów parametrów skojarzonych z każdym elementem podrzędnym. Ostatni węzeł pokazuje dane wyjściowe używane do pobierania wartości parametrów.
