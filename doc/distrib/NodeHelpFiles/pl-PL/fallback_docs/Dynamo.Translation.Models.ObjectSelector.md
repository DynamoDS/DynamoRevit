## Informacje szczegółowe
Węzeł Select Geometry File Objects zawęża zakres importowanej geometrii, umożliwiając ręczne wybieranie obiektów, które mają być przetwarzane przez wykres.

W poniższym przykładzie geometria programu CAD jest importowana i używana w węźle Select Geometry File Objects. Określone obiekty są ręcznie wybierane do wydruku, na przykład obiekty o identyfikatorach 16, 27 i 33 pokazane tutaj.
