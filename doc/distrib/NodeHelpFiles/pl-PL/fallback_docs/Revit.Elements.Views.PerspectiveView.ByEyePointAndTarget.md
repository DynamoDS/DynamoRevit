## Informacje szczegółowe
Węzeł PerspectiveView.ByEyePointAndTarget tworzy nowy perspektywiczny widok 3D programu Revit przy użyciu punktu obserwacji, punktu docelowego, nazwy i wartości logicznej isolateElement.

W poniższym przykładzie w dodatku Dynamo zostają utworzone 2 punkty, które są używane jako punkt obserwacji kamery i punkt docelowy. Są one używane jako dane wejściowe węzła PerspectiveView.ByEyePointAndTarget wraz z nazwą i wartością logiczną. Wynikiem jest nowy widok perspektywiczny programu Revit patrzący od punktu obserwacji do punktu docelowego.
