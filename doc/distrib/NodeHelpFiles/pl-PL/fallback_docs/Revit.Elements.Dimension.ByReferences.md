## Informacje szczegółowe
Węzeł Dimension.ByReferences umieszcza wymiar wzdłuż linii wejściowej w wybranym widoku przy użyciu podanych odniesień. Wynikiem jest element wymiaru programu Revit.

W poniższym przykładzie zostaje utworzonych kilka punktów i są one łączone z węzłami Line w celu wygenerowania krzywych modelu w programie Revit. Krzywe modelu są następnie przekształcane w odniesienia do krzywych programu Revit. Odniesienia są łączone w listę i używane jako dane wejściowe „references” węzła Dimension.ByReferences. Są tworzone dodatkowe linie, aby zdefiniować umieszczenie i kierunek wymiarów. Aktywny widok programu Revit jest również dostarczany jako dane wejściowe „view”.
