## Informacje szczegółowe
Węzeł Filter Geometry File Objects udostępnia reguły filtrowania obiektów przetwarzanych między systemami.

W poniższym przykładzie plik „North Arrows.dwg” jest importowany do dodatku Dynamo, a węzeł Filter Geometry File Objects dostosowuje wyszukiwanie, aby wyświetlić tylko obiekty, w przypadku których identyfikator warstwy wynosi 13. Ostatni węzeł wyświetla wszystkie obiekty z tymi właściwościami.
