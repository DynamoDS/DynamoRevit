## Informacje szczegółowe
Węzeł Parse Unit Input akceptuje wartość liczbową wraz z typem jednostki, umożliwiając zdefiniowanie wielkości, takiej jak długość, powierzchnia, objętość, kąt lub inna mierzalna wartość w kontrolowanym formacie.

W poniższym przykładzie węzeł Parse Unit Input jest używany z wartością 10 i jednostką Feet (Stopy). Dane wyjściowe to wartość System.Double o wartości 10 i nazwa jednostki Feet.
