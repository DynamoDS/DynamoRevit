## Informacje szczegółowe
Węzeł Tag.LeaderElbow zwraca punkt zagięcia linii odniesienia oznaczenia. Dane wejściowe to element oznaczenia programu Revit, a dane wyjściowe to punkt dodatku Dynamo reprezentujący położenie kolana linii odniesienia.

W poniższym przykładzie z aktywnego widoku programu Revit zostaje wybrana etykieta i zostaje ona użyta jako dane wejściowe dla węzła Tag.LeaderElbow. Wynikiem jest położenie punktu, w którym są zagięte poszczególne linie odniesienia oznaczenia.
