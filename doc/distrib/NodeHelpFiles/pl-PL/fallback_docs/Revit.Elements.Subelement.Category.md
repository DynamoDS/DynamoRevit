## Informacje szczegółowe
Węzeł Subelement.Category pobiera kategorię przypisaną do elementu podrzędnego programu Revit. Elementy podrzędne są komponentami lub częściami większego elementu programu Revit, takimi jak warstwy, szprosy, panele ścian osłonowych, zbrojenia lub geometria zagnieżdżona, które mogą istnieć wewnątrz elementu nadrzędnego.

W poniższym przykładzie wszystkie elementy w bieżącym widoku zostają wybrane i przefiltrowane, aby wyświetlić tylko te elementy, które zawierają elementy podrzędne. Elementy podrzędne są następnie używane jako dane wejściowe węzła Subelement.Category. Wynikiem jest lista kategorii skojarzonych z każdym elementem podrzędnym.
