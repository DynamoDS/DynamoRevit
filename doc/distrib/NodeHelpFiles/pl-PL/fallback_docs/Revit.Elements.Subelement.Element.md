## Informacje szczegółowe
Węzeł Subelement.Element zwraca element nadrzędny programu Revit, do którego należy dany element podrzędny.

W poniższym przykładzie wszystkie elementy w bieżącym widoku zostają wybrane i przefiltrowane, aby wyświetlić tylko te elementy, które zawierają elementy podrzędne. Elementy podrzędne są następnie używane jako dane wejściowe węzła Subelement.Element. Wynikiem jest lista elementów nadrzędnych skojarzonych z każdym elementem podrzędnym.
