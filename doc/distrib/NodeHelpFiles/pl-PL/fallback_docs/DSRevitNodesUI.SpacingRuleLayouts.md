## Informacje szczegółowe
Węzeł Spacing Rule Layout pobiera układ reguły odstępów z podzielonego elementu ścieżki. Podzielona ścieżka jest używana jako dane wejściowe, a wynikiem jest bieżąca reguła układu odstępów, która steruje rozmieszczaniem punktów wzdłuż ścieżki.

W poniższym przykładzie z modelu programu Revit zostaje wybrana podzielona powierzchnia i zostaje ona użyta jako dane wejściowe do zmodyfikowania jej parametrów. Węzeł ciągu udostępnia nazwę parametru „Layout”, a węzeł Spacing Rule Layout dostarcza wartość typu reguły odstępów. Wykres aktualizuje regułę układu podzielonej powierzchni do wartości „FixedNumber (Stała liczba). Wynikiem jest zmodyfikowany element podzielonej powierzchni.
