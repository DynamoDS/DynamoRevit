## Informacje szczegółowe
Węzeł Code Block zapewnia kompaktowy format tekstowy umożliwiający pisanie kodu DesignScript bezpośrednio w dodatku Dynamo. Pozwala to tworzyć wartości, wykonywać obliczenia, definiować zmienne i tworzyć logikę. Węzeł Code Block może zawierać pojedyncze wartości, listy, zakresy, wyrażenia matematyczne, wartości ciągów, wywołania funkcji i przypisania zmiennych.

W poniższym przykładzie węzeł Code Block demonstruje wyrażenie matematyczne. Aby uzyskać więcej informacji, zapoznaj się z [podręcznikiem języka DesignScript](https://dynamobim.org/wp-content/links/DesignScriptGuide.pdf).
