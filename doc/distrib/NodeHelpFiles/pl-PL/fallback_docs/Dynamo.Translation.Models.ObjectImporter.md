## Informacje szczegółowe
Węzeł Import Geometry File importuje geometrię zewnętrzną lub dane modelu do dodatku Dynamo, dzięki czemu można je wyświetlać i filtrować oraz używać ich w dalszych procesach. Działa on jako główny punkt wejściowy do przenoszenia obsługiwanej importowanej zawartości do wykresu, umożliwiając dodatkowi Dynamo interpretowanie przychodzącego pliku lub obiektu i uwidocznienie go do dalszego przetwarzania.

W poniższym przykładzie zostaje wybrany plik North Arrows.dwg i jest on używany jako dane wejściowe węzła Import Geometry File. Wynik zapewnia dostęp do całej geometrii i skojarzonych danych zawartych w importowanym pliku.
