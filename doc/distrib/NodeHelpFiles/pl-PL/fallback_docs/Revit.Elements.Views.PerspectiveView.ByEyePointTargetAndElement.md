## Informacje szczegółowe
Węzeł PerspectiveView.ByEyePointTargetAndElement tworzy nowy perspektywiczny widok 3D programu Revit przy użyciu punktu obserwacji, punktu docelowego, elementu, nazwy i wartości logicznej isolateElement.

W poniższym przykładzie jest wybierany element programu Revit, który służy jako punkt skupienia widoku perspektywicznego. Powstaje jeden punkt dla położenia kamery, a drugi dla położenia docelowego. Są one używane jako dane wejściowe węzła PerspectiveView.ByEyePointTargetAndElement wraz z wybranym elementem. Wynikiem jest nowy widok perspektywiczny skierowany od punktu obserwacji do punktu docelowego, z zakresem widoku opartym na wybranym elemencie.
