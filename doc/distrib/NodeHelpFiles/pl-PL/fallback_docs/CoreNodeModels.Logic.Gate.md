## Informacje szczegółowe
Węzeł Gate (Bramka) steruje dopuszczalnością danych wejściowych na podstawie wartości logicznej. Jeśli bramka jest otwarta (Prawda), dane wejściowe są przekazywane na wyjście. Jeśli bramka jest zamknięta (Fałsz), dane wejściowe są blokowane.

W poniższym przykładzie węzeł Gate zapobiega rozbijaniu geometrii przy każdym uruchomieniu wykresu. Gdy bramka jest otwarta (Prawda), nowo utworzona geometria przechodzi przez nią i jest rozbijana. Gdy bramka jest zamknięta (Fałsz), geometria jest blokowana i nie jest przekazywana ani rozbijana ponownie.
