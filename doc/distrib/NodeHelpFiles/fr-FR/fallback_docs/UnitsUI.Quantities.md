## Description approfondie
Quantities fournit un type de grandeur sélectionnable, par exemple Longueur, Surface ou Volume, et extrait les définitions d'unités associées. Ces grandeurs représentent le type de mesure décrit, et non la valeur d'unité réelle. Par exemple, Longueur est la grandeur, tandis que Pieds ou Mètres sont des unités qui appartiennent à cette grandeur.

Dans l'exemple ci-dessous, Quantities est utilisé pour sélectionner une valeur telle que Longueur, Surface ou Volume et extraire les définitions d'unités associées.
