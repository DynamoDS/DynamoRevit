## Description approfondie
PerspectiveView.ByEyePointAndTarget crée une vue 3D en perspective Revit à l'aide d'un point d'observation, d'un point cible, d'un nom et d'une valeur booléenne isolateElement.

Dans l'exemple ci-dessous, deux points sont créés dans Dynamo et utilisés comme point d'observation de la caméra et point cible. Ils sont utilisés comme entrées pour PerspectiveView.ByEyePointAndTarget, avec un nom et une valeur booléenne. La sortie est une nouvelle vue en perspective Revit orientée du point d'observation vers le point cible.
