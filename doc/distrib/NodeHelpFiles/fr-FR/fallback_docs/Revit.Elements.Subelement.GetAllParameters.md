## Description approfondie
Subelement.GetAllParameters récupère les ID de paramètres Revit internes des sous-éléments, et non les noms d'affichage des paramètres.

Dans l'exemple ci-dessous, tous les éléments de la vue active sont sélectionnés et filtrés afin d'afficher uniquement les éléments qui contiennent des sous-éléments. Les sous-éléments sont ensuite utilisés comme entrée pour Subelement.GetAllParameters. La sortie est une liste d'ID de paramètres associés à chaque sous-élément. Le dernier nœud montre la sortie utilisée pour récupérer les valeurs des paramètres.
