## Description approfondie
Units fournit une liste des types d'unités disponibles à utiliser lorsqu'un autre nœud nécessite une entrée DynamoUnits.Unit. La sortie inclut des types d'unités tels que longueur, surface, volume, angle, ainsi que d'autres types pris en charge selon la version de Dynamo.

Dans l'exemple ci-dessous, Units génère une liste d'objets d'unité Dynamo. Ces unités peuvent ensuite être sélectionnées ou filtrées, puis transmises aux nœuds qui nécessitent une entrée DynamoUnits.Unit.
