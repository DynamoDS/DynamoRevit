## Description approfondie
Dimension.ByReferences place une cote le long de la ligne d'entrée dans la vue sélectionnée, à l'aide des références données. La sortie est un élément Cote Revit.

Dans l'exemple ci-dessous, plusieurs points sont créés et connectés à l'aide de nœuds Line afin de générer des courbes de modèle dans Revit. Les courbes de modèle sont ensuite converties en références de courbe Revit. Les références sont combinées dans une liste et utilisées comme entrée references pour Dimension.ByReferences. Des lignes supplémentaires sont créées pour définir le positionnement et l'orientation des cotes. La vue Revit active est également fournie comme entrée view.
