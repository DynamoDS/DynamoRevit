## Description approfondie
Ce noeud récupère le ScheduleFieldId associé à un ScheduleFilter donné.  Chaque filtre de nomenclature dans Revit est lié à un champ spécifique (par exemple, Niveau, Famille et Type, Zone). Ce noeud expose cette connexion en renvoyant l'identificateur de champ utilisé par le filtre.

Dans cet exemple, un filtre de nomenclature est créé et utilisé comme entrée dans ScheduleFilter.FieldId.
