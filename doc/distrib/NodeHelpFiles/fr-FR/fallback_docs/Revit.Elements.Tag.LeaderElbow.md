## Description approfondie
Tag.LeaderElbow renvoie le point de pliage de la ligne de repère d'une étiquette. L'entrée est un élément d'étiquette Revit, et la sortie est un point Dynamo représentant l'emplacement du coude du repère.

Dans l'exemple ci-dessous, une étiquette est sélectionnée dans la vue Revit active et utilisée comme entrée pour Tag.LeaderElbow. La sortie est l'emplacement du point où chaque repère d'étiquette se plie.
