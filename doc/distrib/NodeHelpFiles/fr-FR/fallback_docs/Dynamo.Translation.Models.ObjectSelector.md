## Description approfondie
Select Geometry File Objects restreint le périmètre de la géométrie importée en permettant de sélectionner manuellement les objets transmis dans le graphe.

Dans l'exemple ci-dessous, une géométrie CAO est importée et utilisée dans Select Geometry File Objects. Des objets spécifiques sont sélectionnés manuellement pour la sortie, comme les objets portant les ID 16, 27 et 33 affichés ici.
