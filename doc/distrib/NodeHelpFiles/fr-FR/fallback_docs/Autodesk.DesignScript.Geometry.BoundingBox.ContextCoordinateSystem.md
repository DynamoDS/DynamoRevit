## Description approfondie
BoundingBox.ContextCoordinateSystem renvoie le système de coordonnées qui définit l'orientation de la boîte englobante, ce qui permet à Dynamo de représenter des boîtes englobantes pivotées ou orientées localement.

Dans l'exemple ci-dessous, une porte est sélectionnée et sa géométrie est utilisée pour générer une boîte englobante. Celle-ci est ensuite utilisée comme entrée de BoundingBox.ContextCoordinateSystem, où le système de coordonnées est exposé.
