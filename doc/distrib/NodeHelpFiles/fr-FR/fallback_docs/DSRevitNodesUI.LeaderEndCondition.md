## Description approfondie
Leader End Condition fournit une valeur de condition de fin de repère sélectionnable depuis Revit. Les options disponibles sont Libre et Attachée.

Dans l'exemple ci-dessous, tous les murs de la vue L1 sont étiquetés. Ces étiquettes sont utilisées, avec la valeur Libre sélectionnée dans Leader End Condition, comme entrées pour définir les valeurs de condition de fin de repère.
