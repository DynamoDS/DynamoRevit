## Description approfondie
Subelement.GetParameterValue récupère la valeur d'un paramètre d'un sous-élément Revit.

Dans l'exemple ci-dessous, tous les éléments de la vue active sont sélectionnés et filtrés afin d'afficher uniquement les éléments qui contiennent des sous-éléments. Les sous-éléments sont ensuite utilisés comme entrée pour Subelement.GetParameterValue, avec les ID de paramètres. La sortie est la valeur du paramètre du sous-élément donné.
