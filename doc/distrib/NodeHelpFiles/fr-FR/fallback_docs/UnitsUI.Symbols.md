## Description approfondie
Symbols fournit une liste sélectionnable de symboles d'unité que Dynamo peut utiliser lors de la mise en forme ou de l'analyse de valeurs basées sur des unités.

Dans l'exemple ci-dessous, Symbols est utilisé pour sélectionner un symbole d'unité dans la bibliothèque de symboles d'unité disponible dans Dynamo. La sortie est un objet DynamoUnits.Symbol qui peut être utilisé comme entrée lors de la mise en forme de valeurs fractionnaires.
