## Description approfondie
Code Block fournit un format compact basé sur du texte pour écrire du code DesignScript directement dans Dynamo afin de créer des valeurs, d'effectuer des calculs, de définir des variables et de créer une logique. Un Code Block peut contenir des valeurs uniques, des listes, des plages, des expressions mathématiques, des valeurs de chaîne, des appels de fonction et des affectations de variables.

Dans l'exemple ci-dessous, un Code Block illustre une expression mathématique. Pour plus d'informations, consultez le [guide DesignScript](https://dynamobim.org/wp-content/links/DesignScriptGuide.pdf).
