## Description approfondie
Spacing Rule Layout récupère la règle de présentation de l'espacement d'un élément de chemin divisé. Le chemin divisé est utilisé comme entrée, et la sortie correspond à la règle de présentation de l'espacement actuelle qui contrôle la distribution des points le long du chemin.

Dans l'exemple ci-dessous, une surface divisée est sélectionnée dans le modèle Revit et utilisée comme entrée pour modifier ses paramètres. Un nœud de type chaîne fournit le nom de paramètre Layout, tandis que Spacing Rule Layout fournit la valeur du type de règle d'espacement. Le graphe met à jour la règle de présentation de la surface divisée en lui attribuant la valeur FixedNumber. La sortie est l'élément de surface divisée modifié.
