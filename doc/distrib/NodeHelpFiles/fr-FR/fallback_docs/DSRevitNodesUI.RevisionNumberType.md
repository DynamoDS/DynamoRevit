## Description approfondie
Select Revision Number Type fournit un type de numérotation des révisions à utiliser dans les workflows liés aux révisions. Les choix disponibles sont Numeric, Alphanumeric ou None.

Dans l'exemple ci-dessous, une révision est créée, et Select Revision Number Type est utilisé comme l'une des entrées.

Pour plus d'informations sur les révisions, consultez la [documentation Revit](https://help.autodesk.com/view/RVT/2025/FRA/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4).
