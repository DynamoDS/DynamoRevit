## Description approfondie
Subelement.Element renvoie l'élément parent Revit auquel appartient un sous-élément donné.

Dans l'exemple ci-dessous, tous les éléments de la vue active sont sélectionnés et filtrés afin d'afficher uniquement les éléments qui contiennent des sous-éléments. Les sous-éléments sont ensuite utilisés comme entrée pour Subelement.Element. La sortie est une liste d'éléments parents associés à chaque sous-élément.
