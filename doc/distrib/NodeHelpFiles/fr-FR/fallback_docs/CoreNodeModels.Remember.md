## Description approfondie
Remember stocke une valeur dans le fichier Dynamo afin que le graphe puisse la rappeler ultérieurement, y compris lorsque l'entrée est nulle. Il est utile pour conserver des données entre les exécutions, maintenir un état ou faire référence à des informations précédemment stockées sans avoir à les recréer à chaque fois.

Dans l'exemple ci-dessous, un seul sol est sélectionné, et la géométrie est extraite et utilisée comme entrée pour Remember. Le résultat stocké est ensuite disponible en sortie afin d'être réutilisé dans le graphe.
