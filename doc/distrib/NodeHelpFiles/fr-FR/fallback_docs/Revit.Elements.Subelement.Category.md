## Description approfondie
Subelement.Category récupère la catégorie attribuée à un sous-élément Revit. Les sous-éléments sont des composants ou des parties d'un élément Revit plus grand, tels que des couches, des meneaux, des panneaux de mur-rideau, des armatures ou une géométrie imbriquée pouvant exister dans un élément parent.

Dans l'exemple ci-dessous, tous les éléments de la vue active sont sélectionnés et filtrés afin d'afficher uniquement les éléments qui contiennent des sous-éléments. Les sous-éléments sont ensuite utilisés comme entrée pour Subelement.Category. La sortie est une liste de catégories associées à chaque sous-élément.
