## Description approfondie
Filter Geometry File Objects fournit des règles de filtrage pour les objets traités entre des systèmes.

Dans l'exemple ci-dessous, le fichier North Arrows.dwg est importé dans Dynamo, et Filter Geometry File Objects est utilisé pour personnaliser la recherche afin d'afficher uniquement les objets pour lesquels LayerID = 13. Le dernier nœud affiche tous les objets possédant ces propriétés.
