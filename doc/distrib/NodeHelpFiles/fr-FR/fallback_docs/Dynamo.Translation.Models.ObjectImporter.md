## Description approfondie
Import Geometry File importe dans Dynamo une géométrie ou des données de modèle externes afin qu'elles puissent être affichées, filtrées ou utilisées dans des workflows en aval. Il sert de point d'entrée principal pour intégrer au graphe le contenu importé pris en charge, ce qui permet à Dynamo d'interpréter le fichier ou l'objet entrant et de l'exposer pour un traitement ultérieur.

Dans l'exemple ci-dessous, le fichier North Arrows.dwg est sélectionné et utilisé comme entrée pour Import Geometry File. La sortie donne accès à toute la géométrie et aux données associées contenues dans le fichier importé.
