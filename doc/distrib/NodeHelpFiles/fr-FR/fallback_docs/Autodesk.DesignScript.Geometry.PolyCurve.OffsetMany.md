## Description approfondie
PolyCurve.OffsetMany décale une PolyCurve pour créer une ou plusieurs nouvelles PolyCurves en fonction de la distance et du plan de décalage d'entrée.

Dans l'exemple ci-dessous, un noeud PolyCurve.ByPoints crée la géométrie d'entrée pour PolyCurve.OffsetMany. Une valeur de distance signée (+ ou -) contrôle le sens du décalage, une valeur booléenne extendCircular détermine la façon dont les arêtes circulaires sont traitées et un vecteur planeNormal définit la direction normale du plan dans lequel le décalage est créé.
