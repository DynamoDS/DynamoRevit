## Description approfondie
Parse Unit Input accepte une valeur numérique avec un type d'unité, et fournit une valeur unitaire permettant de définir une grandeur telle qu'une longueur, une surface, un volume, un angle ou toute autre valeur mesurable dans un format contrôlé.

Dans l'exemple ci-dessous, Parse Unit Input est utilisé avec une valeur de 10 et l'unité Pieds. Les sorties sont une valeur System.Double de 10 et le nom d'unité Pieds.
