## Description approfondie
Mesh.BoundingBox renvoie la boîte englobante d'un maillage donné.

Dans l'exemple ci-dessous, des points sont générés et utilisés pour créer un maillage, qui est ensuite utilisé comme entrée de Mesh.BoundingBox. La sortie est une boîte englobante utilisée pour extraire le MinPoint.
