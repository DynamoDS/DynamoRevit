## Description approfondie
Select Revision permet de sélectionner une révision dans le projet Revit actif.

Dans l'exemple ci-dessous, Select Revision est utilisé avec l'option "Seq. 1 - Conception schématique" sélectionnée. La sortie est ensuite utilisée comme entrée pour récupérer la date et le statut de publication de la révision.

Pour plus d'informations sur les révisions, consultez la [documentation Revit](https://help.autodesk.com/view/RVT/2025/FRA/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4).
