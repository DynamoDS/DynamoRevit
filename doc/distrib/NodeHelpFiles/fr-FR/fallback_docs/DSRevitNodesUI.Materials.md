## Description approfondie
`Materials` permet de sélectionner un seul élément de matériau dans la liste alphabétique de tous les éléments de matériau du document actif (fichier).

Le matériau sélectionné peut servir d'entrée à des noeuds tels que `Element.SetParameterByName` pour affecter un matériau au paramètre de matériau d'un élément, ou être utilisé avec les noeuds `Material` pour interroger ses propriétés.
