## Description approfondie
FilterRule.ByRuleType crée une règle de filtre Revit basée sur un type de règle, un paramètre et une valeur de comparaison sélectionnés.

Dans l'exemple ci-dessous, un type de mur est identifié, et le paramètre Fire Rating est utilisé comme entrée pour FilterRule.ByRuleType, avec une valeur et un type de règle. La sortie est une règle de filtre qui est ensuite appliquée à une vue.
