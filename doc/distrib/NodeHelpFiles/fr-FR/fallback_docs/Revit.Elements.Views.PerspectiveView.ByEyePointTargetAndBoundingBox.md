## Description approfondie
PerspectiveView.ByEyePointTargetAndBoundingBox crée une vue 3D en perspective Revit à l'aide d'un point d'observation, d'un point cible, d'une boîte englobante, d'un nom et d'une valeur booléenne isolateElement.

Dans l'exemple ci-dessous, des points sont créés pour définir le point d'observation et l'emplacement cible de la vue 3D. Une boîte englobante est également créée pour contrôler les limites de cadrage de la vue. Ces entrées sont utilisées avec PerspectiveView.ByEyePointTargetAndBoundingBox, avec un nom et une valeur booléenne. La sortie est une nouvelle vue 3D en perspective dans Revit.
