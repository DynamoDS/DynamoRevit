## Description approfondie
Select Revision Visibility fournit un mode de visibilité des révisions Revit. Les options disponibles sont CloudAndTagVisible, TagVisible et Hidden.

Dans l'exemple ci-dessous, une révision est créée à l'aide de Select Revision Visibility comme l'une des entrées.

Pour plus d'informations sur les révisions, consultez la [documentation Revit](https://help.autodesk.com/view/RVT/2025/FRA/?guid=GUID-0F2A9A13-0A88-4D18-9DF7-C0296DE0FFE4).
