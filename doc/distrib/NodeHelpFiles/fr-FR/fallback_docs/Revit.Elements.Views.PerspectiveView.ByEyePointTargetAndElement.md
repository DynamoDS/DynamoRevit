## Description approfondie
PerspectiveView.ByEyePointTargetAndElement crée une vue 3D en perspective Revit à l'aide d'un point d'observation, d'un point cible, d'un élément, d'un nom et d'une valeur booléenne isolateElement.

Dans l'exemple ci-dessous, un élément Revit est sélectionné et utilisé comme élément de référence pour la vue en perspective. Un point est créé pour l'emplacement de la caméra et un autre pour l'emplacement cible. Ils sont utilisés comme entrées pour PerspectiveView.ByEyePointTargetAndElement, avec l'élément sélectionné. La sortie est une nouvelle vue en perspective orientée du point d'observation vers le point cible, avec des limites de vue basées sur l'élément sélectionné.
